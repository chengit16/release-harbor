# 渠道规格

- 应用宝只允许 Android APK；鸿蒙只允许独立 harmony 应用与正式 .app，跨平台绑定和产物拒绝。
- 两家分别配置账号、数字商店目标，沿用公共自动准备与一次明确确认，不上传秘密到普通 API。
- 来源、版本、策略和字节变更均拒绝旧授权；不能以 SDK 成功日志替代商店回执。
- 应用宝立即发送 deploy_type=1，定时发送 2 与秒级 deploy_time；不重复填已有资料，不携带线上旧包流水。
- 鸿蒙上传、解析、版本关联及审核的事实必须分开；解析不明、条件缺失时停止，不能显示送审成功。
- 所有开发测试使用合成材料和注入网络，真实操作由用户在具体计划触发。
