# 设计

## 应用宝

腾讯官方公开发布 API 文档以主账号 UserID、access_secret、数字 app_id 和包名定位已有应用。账号只存 UserID／access_secret；app_id 单独保存在绑定，避免把应用目标变成账号秘密。准备固定公开名称、版本及资料摘要，私人测试账号不进入合同或指纹。查询失败不得用空对象继续上传。更新仅发送本次包流水、MD5、版本特性和上架方式，未变更资料省略以沿用后台。

可信适配固定 HMAC-SHA256 排序签名、官方查询／上传信息／更新路由；COS 预签名 URL 限定 HTTPS 腾讯云域名，不重定向，不传签名密钥到 COS。独立复核 APK 字节和原生架构，单普通包或单纯 64 位包按实际架构选择 apk32／apk64 字段；本轮不支持双包。首次写入前持久化许可；上传和提交不重试。明确 ret=0 仅表示审核受理。

## 鸿蒙

新增 harmony 应用平台，正式产物为 .app，bundleName 与数字 App ID 独立。只读身份从受限 ZIP 元数据提取，摘要和身份在接收、预检和执行副本重复核对；不信任扩展名或网页声明。账号初批使用 API 客户端 Client ID／Client Secret，与已有华为 Android 档案分渠道保存。

按官方 v3 Publishing API 核实目标与来源、复用现有资料；上传使用 v2 upload multipart 的 APP 文件类型及 v3 app-package-info 关联，保留每片摘要及 ETag，不向任意地址附带控制面认证。软件包解析状态未明确成功不得自动送审。更新说明及立即／定时随冻结意图发送；完整送审结果与仅上传、草稿关联分别表示。任何未明确的字段语义保持拒绝，不推测成功。

## 恢复与兼容

新动作、来源及结果增加存储版本，旧快照不回填，不改指纹。控制面不加载 SDK 或秘密；所有网络与材料在独立可信 worker。许可后任意超时、中断或非确定响应均待核对；未知目标先人工核对，重启不重放。隔离自动化及 Chrome 与真实商店验收独立记录。
