# 商店绑定展示设计

绑定查询、账号目录及编辑生命周期仍由原面板持有，新 BindingList 只展示公开数据。桌面 Ant Design Table 对齐渠道、目标、账号和操作；版本置于渠道次级文字中。手机仅挂载 Card／Descriptions，完整包名换行，目标支持复制，避免隐藏布局重复挂载影响焦点和可访问性。

添加入口放在标题右侧，数量由真实绑定列表计算。删除旧的固定支持渠道文案和统一“未预检”标签：绑定只保存配置，不能代表当前预检历史。账号目录正在读取、不可用及找不到原引用分别表达，不伪造账号丢失。

编辑仍使用原表单与版本冲突机制；退出后把焦点返回原渠道入口，新增后返回添加入口。无接口或存储变更，无商店请求。浏览器用独立应用的六渠道合成数据检查密度、长目标、手机布局、编辑焦点；既有发布流程继续回归。
