# 执行恢复规格

- 查询及刷新不触发商店请求；详情展示固定原因、建议、目标、版本、摘要及原始执行事实。
- 原因区分计划失效、账号版本变化、产物复核失败、商店只读核对失败、上传准备失败、许可拒绝、执行器中断和远端结果不明。历史无原因时如实提示。
- 人工核对写接口要求精确本机来源、专用请求头、完整父级归属、摘要与版本一致、明确同意。
- 执行中、成功或执行前失败不能进行未知结果核对。相同重复提交幂等，相反结论拒绝；核对不能修改原回执或重新派发。
- 未核对目标不能执行；已确认有草稿的相同产物不能重新上传；无草稿结论允许新计划显式执行。
- 浏览器验证详情、未勾选拒绝、取消无副作用、人工结论持久化、窄屏和无自动上传。
