# 页面内账号配置要求

## 用户流程

- 用户必须能在建立商店绑定时选择同渠道已有账号或打开新增向导，不要求填写内部 reference 或执行 CLI。
- 向导必须收集名称及正确渠道的材料；成功后自动回填原绑定表单，取消时保留公开草稿并恢复焦点。切换应用后的迟到回调不能影响新上下文。
- 保存只表达本机配置事实，不自动保存绑定、鉴权或发布。预检仍绑定具体应用、商店目标、产物、档案版本及时间。

## 本机录入边界

- 浏览器材料只能在局部录入模块短暂持有，并直接发送给本机配置服务；业务 API、公开 contracts、普通查询、日志和缓存不得包含材料。
- 会话必须限定启动实例、可信 local 工作空间、精确来源、渠道、操作及有效期。错误／缺失来源、过期、跨渠道和未知字段必须拒绝，不能仅用 localhost 或 CORS 代替授权检查。
- 华为及 Apple 材料必须独立校验；Apple 只接受受限大小的有效私钥内容，不能接收服务器文件路径。未支持环境不得降级为明文存储。

## 结果与恢复

- 同一次保存必须关联固定 reference 和操作 ID，重复请求不能再次写入；超时先查询安全结果，不自动重新提交秘密。
- 关闭保存中的向导不得承诺取消存储；崩溃或跨文件状态无法核实时保留待核对，不能伪造成功或自行覆写。
- 已有 CLI Profile 继续可选，缺少名称时回退原引用；无效引用明确提示，不自动替换账号。
- 自动测试只使用隔离目录、内存安全库和合成材料；真实安全存储录入及真实渠道核验必须单独记录。

## 账号维护

- 待核对账号必须提供可操作的恢复路径：显式核对本机材料、重新录入、名称编辑与删除，不要求 CLI，也不自动处理用户的真实账号。
- 核对通过只表示材料完整可读且格式有效；无材料或系统拒绝时保持待核对，提示授权或重新录入，不显示远端鉴权通过。
- 重新录入必须保留原引用及渠道，材料仍直传独立配置进程，不回显旧秘密。管理版本在创建会话及实际保存时均核对，拒绝旧页面覆盖；保存后旧预检失效。
- 删除必须经过页面二次确认，并在服务端与绑定写入共用的边界核对无关联应用。删除失败／中断保留隔离记录，不能让缺失材料的账号仍可选择。
- 进程重启后仅凭元数据不能恢复已配置；保存适配必须完整读回核对，长凭据、中文、标点及加密私钥不能被截断或损坏。
