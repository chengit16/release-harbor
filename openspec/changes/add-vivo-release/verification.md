## 回归覆盖

- 正式账号字段严格校验、安全存储、本机重新核对及安全目录。
- HMAC-SHA256 原值签名，固定正式网关、无重定向、无写重试。
- 只读查询严格匹配普通应用、包名、已上架／审核状态、构建号和兼容设备；不透传私人详情。
- 立即／定时字段映射和未来时间检查，来源变化、旧版本、产物变化和许可拒绝时不上传。
- 上传回执包名、版本、MD5 和流水号匹配；失败不继续同步更新。
- 同步明确成功才记录更新已接收；非零业务码、超时及不明格式保持待核对并保留安全诊断。
- 真实 APK 在完整 runner 复核独立副本，单次查询和许可。
- schema7 兼容读取及 schema8 写入，不修改旧摘要；重复确认只创建一个尝试。
- 页面新增账号、包名绑定、定时准备、关闭摘要不上传、一次确认及刷新不重放；窄屏摘要与材料输入不溢出。
