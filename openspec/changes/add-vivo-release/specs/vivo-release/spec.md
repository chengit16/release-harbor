# vivo 发布要求

- 页面须能创建、编辑、核对 vivo 正式 API 账号，通过包名建立 Android 绑定。
- 准备发布须仅执行只读目标查询，失败保留固定原因，不授权写操作。
- 用户须能选择立即或未来定时上架，摘要须展示真实的提交动作与上架意图。
- 确认一次后，执行器须复核计划、来源、产物和凭据版本，并消费一次授权。
- 上传回执缺失或不匹配须停止同步更新；同步响应须 code=0 且无非零 subCode，才记录平台已接收。
- 网络、HTTP、格式、鉴权、限流、目标状态和版本错误须以固定安全分类展示；不泄露供应商正文或秘密。
- 刷新或重复点击不得重放已消费授权；未知结果须保持人工核对流程。
