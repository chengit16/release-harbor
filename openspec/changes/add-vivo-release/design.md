# vivo 接入设计

## 接口与数据边界

固定正式网关 https://developer-api.vivo.com.cn/router/rest，只允许 app.query.details、app.upload.apk.app 和 app.sync.update.app。公共参数 ASCII 排序、原值 HMAC-SHA256 签名，签名后编码；文件不参与签名。总接入说明与 Java 示例要求 HMAC-SHA256，旧业务页的 hmac 不作为失败重试分支。

公开合同仅新增来源构建号、兼容设备。查询中的测试账号、备注、联系方式及附件不透传或写日志。更新接口的可选商店资料不发送，以免将查询返回的查看 URL 当成文件流水号。兼容设备必须从查询取得，缺失拒绝而非默认改成手机。

## 检查和执行

查询必须匹配包名、普通应用类型、已上架且非待审核／草稿状态；只支持已知可更新状态。本地构建号为正整数且高于来源。准备和执行各查询一次，执行重新比对来源；计划冻结这些安全数据并参与完整摘要。

上传前核对真实独立副本 SHA-256、大小、MD5、账号版本、上架时间及限定授权。父进程持久化远端许可后才能上传。上传返回的包名、构建号、MD5、版本名称和流水号须匹配，才继续一次同步更新。同步成功只显示 vivo 已接收更新提交；不推断审核或上架。所有写请求无重试，许可后任何不明结果均待核对。

## 时间与兼容

立即映射 onlineType=1；定时映射 onlineType=2 和 scheOnlineTime。公开意图保持 UTC，网关无时区字段，按中国平台 Asia/Shanghai 转 yyyy-MM-dd HH:mm:ss；官方字段页未明示时区，此映射需真实后台验收。到期不得降级立即。新版文件格式升至 schema8，旧记录原样读取，不回填 vivo 或改变旧摘要。
