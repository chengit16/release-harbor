# 设计与兼容

## 导航和界面

管理员使用 `view=members` 独立页面，支持刷新和窄屏菜单；页头只保留身份和退出。成员列表显示状态与授权摘要，添加及重置在临时窗口完成，密码不持久化。授权每应用一张卡，渠道只说明覆盖数量，未配置渠道的应用也可预先授权。

## 权限模型

`LocalTeamPermissions.applications` 保存项目、应用及操作集合；省略时兼容旧账号。服务端校验真实应用归属，按应用授权优先于旧渠道授权。操作不再逐渠道勾选，准备与确认涵盖该应用各渠道真实动作，但原有摘要确认、一次性授权和临执行校验继续生效。

旧 `grants` 保持原指纹及动作范围。管理员显式编辑某应用操作时，才替换该应用旧授权；只改菜单不会扩大范围。失效应用授权可明确移除，目录故障不能伪装成空权限。

## 身份切换

无权访问当前菜单时，画面和 URL 同时回退到允许的入口，防止旧管理员菜单的参数白名单丢弃成员的审核详情定位。历史配置变化后的记录仍检查当前绑定一致性，不用新应用权限恢复旧发布资格。
