# 小米更新规格

## 账号及目标

页面能够创建、重录、核对、编辑名称及删除小米档案。材料不经过普通 API、不落浏览器存储；绑定只能使用当前应用包名。关联删除保护继续有效。

## 自动准备

用户选择小米绑定与 APK，填写说明、隐私政策及 PNG 图标后准备。账号无效、目标不匹配、没有明确更新许可或资料摘要错误时拒绝；不创建授权。刷新读取原进度。

## 明确执行

摘要展示“小米提交审核”、实际名称、包名、版本、图标、隐私政策及说明。关闭不执行，用户勾选后一次确认创建并消费限定授权。无效、过期、重复、目标阻塞和错误渠道不得绕过服务端校验。

## 回执及恢复

只有明确受理响应可显示“已提交审核”，不能显示草稿、审核通过或上架。超时、不明确响应及许可后退出保留待核对，用户人工核对不能恢复旧授权或自动重试。历史华为结果继续可读。
