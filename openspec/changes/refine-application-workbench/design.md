# 交互与边界

- 全部项目页保留项目概览；项目应用列表与选中应用详情互斥。应用工作台使用完整内容宽度，顶部保留项目面包屑、应用名称、平台、包身份、应用切换及返回列表入口。
- 复用既有 URL 定位，增加受限的 tab 参数，刷新及浏览器前后退恢复项目、应用与页签；切换应用时销毁旧表单与轮询，不复用其他应用草稿。
- 预检配置紧凑排列商店绑定和已检查安装包，保留显式执行按钮及上传权限未验证提示。最新结果展示三项核验和当前有效性；不得用旧成功覆盖新失败，或把已失效成功当作当前通过。
- 历史以 Ant Design Table 每页五条展示时间、账号、安装包版本和结果；详情用 Drawer 展示原引用、摘要、绑定版本、检查时间和失效原因。移动端隐藏次要列并在详情保留全部事实，不让页面横向溢出。
- 账号名称、文件名和版本来自当前公开目录，仅用于可读标签；关联记录缺失时使用固定兜底并在详情保留原始 ID，不伪造历史名称快照。原始记录及当前有效性继续由服务端决定。
- 浏览器验收使用隔离服务、合成账号和实际检查产物，验证记录分页与按需详情、最新失败／失效事实、导航恢复及桌面窄屏布局；不请求真实商店或改写用户记录。
