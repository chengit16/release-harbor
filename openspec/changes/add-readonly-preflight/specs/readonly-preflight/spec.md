# 新增需求

- Profile 别名合法、元数据存在不代表凭据有效。缺失、平台错配和无法读取安全材料应失败或无法验证。
- 秘密只在本机可信终端与 worker 内存出现，不进入公开合同、API 请求、回执、日志、命令参数和测试真实账号。
- 预检重新核对实际产物与快照、绑定及凭据版本；跨归属、旧 revision、非 ready 产物和未知请求字段被拒绝。
- 只有产物、鉴权和明确目标查询都通过，结果才是 passed；uploadPermission 始终为 not_verified。
- 绑定、产物、Profile 版本变化或超过有效期后，旧成功结果不能继续显示有效。
- 预检网络传输仅允许明确的鉴权／只读端点；不自动重试，不允许上传、送审或发布。
- 替身控制所有网络与 Keychain 场景；普通测试和浏览器冒烟不得访问真实账号或商店。
- 失联、重启和持久化失败不能被描述为核验通过；历史记录不被自动覆盖或重跑。
