# P1-3 本地工程验收

**日期：**2026-11-03。

## 已实现

- 可信终端 `pnpm credentials add/list`，秘密关闭回显、不接受秘密参数、不覆盖已有档案；macOS Keychain 使用独立 service，Apple 文件使用 SDK 的加密 Vault。
- 安全目录合同、独立只读 worker、版本与 nonce 校验、固定商店鉴权／查询白名单、无重定向或自动重试。
- 控制面验证完整父级归属、绑定和档案版本、产物 ready 状态；异步任务返回 202，独立记录，不解析秘密。
- 产物真实字节与身份复核，预检事实关联绑定版本、目录版本及产物摘要；五分钟有效期和变化失效。查询历史通过记录时重新检查磁盘字节。
- `preflights.json` 串行原子存储、损坏保护、running 重启恢复为无法验证／中断，不自动重跑。
- 白色主题 Ant Design 预检页签、明确缺少档案的提示、显式只读操作、三项检查及上传权限未验证的历史记录。

## 自动验证

- `pnpm typecheck`：通过。
- `pnpm test`：29 项通过，无跳过；其中 7 项新增预检测试。
- `pnpm build`：通过。
- `pnpm format:check`：通过。
- `pnpm test:smoke`：通过，真实 Chrome 使用临时数据目录，覆盖既有流程和新增只读预检页签、键盘选择、缺少档案禁止运行、API 拒绝及桌面／390px 窄屏。

测试中使用内存 SecretStore、合成 P-256 私钥、合成 IPA 以及注入的 HTTP transport。覆盖华为／Apple 成功和目标错配、拒绝及网络失败、秘密不落盘／目录不解密、版本失效、字节变化、并发拒绝、历史读取、恢复与损坏保护。真实子进程只读取隔离空凭据目录，不访问个人真实 Keychain 或商店。

## 未验收与边界

- 未录入或读取真实账号，未执行真实华为／Apple 只读核验，也没有商店写操作。
- Keychain 录入需用户在 macOS 本机终端主动执行；本轮未通过真实 Keychain 写入验证，自动测试使用内存替身。
- Apple API Key 只读核验不等于构建上传凭据、工具及权限已完整配置。上传权限固定未验证。
- 绕过产品 CLI 直接修改 Keychain 无法由 Vault 元数据版本自动侦测，后续执行必须重新核验。
- P1-4 的冻结计划及人工授权、P1-5 的真实执行和回执尚未实现；第一期整体仍未完成。
- 未安装 OpenSpec CLI，本轮未声称通过其命令校验。
