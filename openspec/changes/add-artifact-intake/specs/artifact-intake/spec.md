# 新增需求

## 需求：接收可追溯字节

- 合法上传先核对项目、应用、平台与限制，再以流式方式写入受控目录。
- 同时发生的第二个任务返回 409；超限、零字节、非法文件名、假声明、内容中断和空间不足不产生可用产物。
- 不存在或跨归属资源返回 404；本地 Host／Origin 与 hosted 保护继续生效。

## 需求：独立可信检查

- 接收后返回真实检查中状态；检查进程根据实际字节取得身份、版本和摘要。
- IPA 必须兼容 XML 与二进制 Info.plist，提取字节直接交给转换器；不得转码原始二进制数据，也不得为了检查修改原 IPA。
- 安装包身份与应用不符、工具不可用、损坏包、摘要变化、进程超时或错误回报均不得标为 ready。
- 任务与回报都核对 nonce、ID 和 inspect-only 范围；路径与 SDK 原始信息不进入公开合同。
- 替身只用于测试控制失败与时序；正常启动必须使用真实独立检查进程。

## 需求：状态与恢复

- 刷新及重启后可读取记录；未完成接收／检查变为中断失败且不重跑。
- 失败清理字节，损坏记录保留原字节并拒绝覆盖。
- 浏览器可完成选择、显式上传、状态轮询、失败反馈与刷新；切换应用后旧响应不进入新视图，窄屏可用。
- 合成测试 IPA 只用于验证 ZIP／plist 解析，不得描述为真实可签名、可安装或商店已受理产物。
