# 产物接入与检查验收记录

**日期：**2026-11-03  
**范围：**第一期 P1-2，本地字节接收、独立进程检查和公开记录。真实商店发布未执行。

## 实现结果

- 应用详情新增“安装包”页签，使用 Ant Design 选择文件和手动触发上传，沿用白色主题。
- 流式接收 APK／IPA，实测长度和 SHA-256；单文件 256 MiB、产物字节预算 2 GiB、64 MiB 磁盘余量、单接收／检查槽位。
- 安全记录与原始字节分离，响应不含内部路径；检查在独立本机进程中执行，API 不导入 SDK。
- 拒绝包身份错配、损坏包、大小／平台不符、符号链接、摘要变化和非 inspect 任务；失败清理本次字节。
- 启动恢复未完成记录为中断失败，不自动重试；未知版本不覆盖，后台存储失败时关闭入口并报错。
- Git 与格式工具只忽略根目录 `/artifacts/` 截图产物，避免同名业务源码目录被意外忽略。

## 边界

仅实现本机父子进程信任，不提供远程执行器配对、凭据预检、签名验证、下载、删除、发布计划或商店写动作。成功产物保留到预算上限，不自动删除。未来执行仍须复核文件摘要；正常记录展示的是带时间的检查事实。

OpenSpec CLI 未安装，未运行其校验。真实账号、生产安装包和渠道操作需在后续阶段另行明确授权并验收。
