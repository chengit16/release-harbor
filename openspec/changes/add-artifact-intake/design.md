# 产物交接设计

## 数据与接口

公开 `ArtifactRecord` 只含 ID、可信归属、原始安全文件名、格式、预期／实际字节数、摘要、检查身份、状态、失败码和 UTC 时间，不含执行器绝对路径。状态为 `receiving → checking → ready/failed`，失败不可自动重试。`ready` 仅代表当前字节的包身份与登记应用相符，不保证签名或商店受理。

- `GET /api/projects/:projectId/applications/:applicationId/artifacts`：返回记录；固定限制由公开 `artifactLimits` 合同共享。
- `GET .../artifacts/:artifactId`：返回单条记录；同时核对所有父级归属。
- `POST .../artifacts`：`application/octet-stream` 原始字节，`x-artifact-name` 是 URI 编码文件名，`x-artifact-size` 声明字节数。完成接收和持久化后返回 202，随后异步检查。

文件名最多 120 字符，不含路径、控制字符或点路径；仅接受与登记平台匹配的 `.apk`／`.ipa`。不接受浏览器提供的路径、检查结果、摘要或工作空间授权。空文件、非法头部拒绝；默认单文件最大 256 MiB，托管文件总预算 2 GiB，保留至少 64 MiB 可用磁盘空间。单进程只允许一个接收／检查任务，忙时返回 409；上传限时 120 秒，检查进程限时 90 秒。字节数以接收流实测为准，长度和声明不一致即失败，不依赖 Content-Length 单独保护。

## 本地职责与信任

API 的自定义 Fastify parser 保留原始流，手动限制字节数和时间，不把大文件缓存在控制面内存。实现依据为 [Fastify 流式 parser 文档](https://fastify.dev/docs/latest/Reference/ContentTypeParser/)。API 只写入专用存储下生成的 UUID 目录，原始文件名不参与文件路径。

`packages/runner-local` 提供受信任的检查子进程边界。父进程固定执行本仓库 worker，通过私有 stdin 交接版本化 inspect-only 任务，包含随机 nonce、任务 ID、目标归属／应用身份、受控存储根和真实摘要。worker 验证任务范围、路径限制、普通文件、大小和摘要，再调用 `provider-app-ship`；执行前后复核，不解析凭据，不执行发布动作。结果必须关联 nonce 和任务 ID，父进程限制输出及超时，丢弃原始 SDK 日志，只接收公开投影或固定失败码。该本地父子进程信任不能替代未来远程执行器配对协议。

缺少 aapt／aapt2 时 APK 检查失败；IPA 依赖 unzip、plutil 等本机工具。不能只凭扩展名或客户端提供的元数据认定检查通过。SDK 只用于执行侧，Web、Domain、API 不直接导入 SDK。

## 持久化与恢复

`artifacts/{UUID}/record.json` 为版本化安全记录，`payload.apk/ipa` 为内部文件；临时文件使用 `.part`。元数据同目录原子替换，进程内队列保护写入。目录、文件权限分别为 0700／0600，不跟随符号链接；内部路径不出现在公开响应和错误中。

接收、检查失败及中断时删除本条临时文件／产物字节，保留失败记录。记录采用不可变归属及受限状态转换。启动扫描残留接收／检查任务，将其标为 `interrupted` 并清理；不自动再次执行检查。检查成功记录的文件缺失或截断时在启动恢复中标记失败。损坏元数据或未知版本拒绝读取和新增，不覆盖原文件；后台持久化失败时关闭后续入口并显式报错，不能停留在假成功。

已检查记录是带时间的历史事实，未来计划／执行仍须重新核对文件摘要。首轮不提供下载、删除和清理历史记录入口；失败字节自动清除，保留成功产物至预算上限。修改配额或引入过期清理需独立需求，不能静默删除用户已有成功产物。

## 页面

应用详情使用“商店绑定／安装包”页签。安装包页用 Ant Design Upload 选择单文件，再显式点击“上传并检查”；允许停止本地等待，但不得承诺已撤销服务端接收。显示大小限制、当前上传／检查阶段、版本、摘要与真实失败原因，轮询在末态或离开页面后停止，失败不自动重传。
