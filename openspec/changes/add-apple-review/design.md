# 设计

公开合同仅含构建、版本、资料缺项与时间；SDK、JWT 和测试账号仅在独立可信 worker。显式读取远端目录与准备均为只读，刷新工作台历史不请求商店；远端状态须用户点击刷新并记录查询时间。目录有界分页，拒绝不完整列表；查询、写入固定 HTTPS 路由，不重定向、不自动重试。

审核意图与既有计划同文件升级为 schema11，使用同一写队列、全局执行槽。不可变快照关联应用、绑定版本、目录版本、具体构建和商店版本、公开资料指纹、说明与自动／手动发布方式，有效五分钟。确认先原子消费再启动 worker，首次商店写入前持久化许可；重启不重放。许可后未知阻止同目标继续执行，需明确人工核对后才能新建操作。旧上传及 Android 记录不改指纹、不回填。

送审执行先重读并比对来源，再设置 releaseType、清除旧 earliestReleaseDate、绑定指定构建、按既有语言更新 whatsNew、创建审核集合、加入本版本、提交审核集合。不得复用包含其他待审项目的集合，不自动替换其他应用或版本。各步骤部分成功仍按未知处理，不自动回滚或重试。明确审核回执只代表受理。

手动上线只允许 PENDING_DEVELOPER_RELEASE、MANUAL、指定构建一致；单独冻结并确认后调用 release request。请求已受理不表示商店已上架，后续只读观察保留状态、来源与时间。资料不完整或没有目标版本时停在准备阶段，引导去后台完善。
