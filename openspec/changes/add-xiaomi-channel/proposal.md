# 小米 Android 渠道接入

按用户 2026-11-04 的优先级，小米是下一个单渠道切片，之后依次 OPPO、vivo、魅族、荣耀，再恢复 iOS；应用宝与华为鸿蒙延后。

目标复用现有工作台和安全执行边界，形成小米账号配置、既有应用绑定、只读预检、更新提交审核及安全回执的独立流程。首轮限定既有应用的版本更新，不做新增应用、资料自动修改、自动上线或多渠道并发。

本次完成规格准备，代码及真实渠道验收尚未开始。实施依据见[第二期计划](../../../docs/plans/phase-2-android-channels-plan.md)及[能力核对](../../../docs/verification/xiaomi-baseline-2026-11-04.md)。
