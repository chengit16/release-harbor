# 小米渠道需求

## 账号与目标

- 小米材料经页面向导安全配置，普通 API 不接收秘密。账号可重新核对、编辑、重新录入，删除受绑定保护。
- 小米账号不可用于华为或 Apple；包名与目标必须匹配当前应用，不能凭空构造数字 App ID。
- 历史华为／Apple 配置、计划及回执保持可读取。

## 只读预检

- 针对实际 APK、账号和目标只运行允许的查询，绝不调用推送接口。
- 查询结果必须能明确核对目标与当前更新许可；错误、缺字段和互相冲突的结果不得通过。
- 结果有时间、有效期、依赖版本和安全原因；材料、目标或字节变化使旧结果失效。

## 更新提交

- 首轮只支持既有应用版本更新；新增应用与其他动作拒绝。
- 执行必须核对确定的“小米提交审核”计划，不能复用华为草稿授权。
- 图标、更新说明及平台要求的其他资料须在确认前准备齐全；非秘密资料固定摘要，秘密不进入公开快照。
- 许可前复核依赖，许可后至多发起一次提交。重复请求返回同一次执行，未知结果阻止直接重发。
- 回执只表达确定事实；提交审核不等于审核通过或上线。

## 验收

- 自动测试使用隔离材料，不能查询或提交真实商店。
- 真实浏览器覆盖录入、绑定、错误、失效、确认、执行事实与窄屏；真实渠道另以明确计划验收。
