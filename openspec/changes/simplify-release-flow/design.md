# 统一准备与确认执行

“准备发布”引用当前已保存的账号、目标、产物及资料，自动完成必要只读预检和快照准备，不向商店写入。用户在同一页面看到结果和摘要，不手动跳转多个页签。错误原地修复后重新准备。

摘要固定真实动作、应用、商店目标、产物版本及摘要、资料与有效期。最终操作明确显示“确认保存草稿”或“确认提交审核”，只产生一次用户执行确认。服务端以预期摘要、明确同意和请求去重保护，当前依赖有效后原子产生／消费限定授权与执行尝试；不能只在前端串联两个请求就声称具备原子语义。

重复点击、丢失响应及重启返回原受理事实，不重复派发。过期或内容变化在原页重新准备并展示新摘要，不能自动延长旧授权。准备取消不执行，执行开始后的关闭不冒充远端撤回。既有历史快照与人工核对记录保留。

当前为方案阶段。具体路由、响应与存储迁移在实现前补充；不增加未使用的通用任务队列或一次开放所有渠道。
