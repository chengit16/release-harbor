# 本机团队身份设计

通过可信本机终端建立唯一首位管理员，安装级账号文件的存在启用认证。文件不在业务恢复代内；服务检测到团队模式后不会因账号文件丢失退回单人。启动仍限定回环；团队 API 进一步要求实际服务端口和同源写请求。每条业务 API 默认只允许管理员，后续切片按资源和动作逐条开放给成员。

账号文件只保存独立随机盐和 scrypt 摘要。会话随机能力仅通过 HttpOnly、SameSite=Strict 的本机 Cookie 返回，控制面存储会话摘要，进程重启后重新登录。成员停用、启用或重置密码均退役旧会话。初次启用必须停止旧工作台及其转发；不能用文件备份或旧二进制绕过团队模式。团队账户与操作系统用户权限是不同边界；能读写服务器数据根的 Mac 用户属于可信宿主管理者。
