# 新增需求

## 需求：独立且可信的应用身份

系统必须将平台包身份与商店 appId 分开存储，应用归属于可信工作空间下的项目。

### 场景：创建和刷新

- 当用户在已有项目内创建合法 Android 或 iOS 应用时，保存应用身份并在刷新或服务重启后可读取。
- 创建不要求商店账号，不触发商店请求。

### 场景：冲突与归属

- 同空间同平台同标识并发创建仅一个成功，另一个返回 409；跨空间可使用相同标识。
- 不存在项目、跨空间项目或不属于指定项目的应用返回 404。
- 客户端注入 workspaceId、未知字段、无效平台或包身份返回 400。

## 需求：维护首批商店绑定

系统必须只开放华为 Android 与 Apple iOS 的配置维护，不将配置保存解释成凭据验证或发布能力完成。

### 场景：绑定与编辑

- 合法绑定返回独立 appId、引用、revision 和 `not_checked`。
- 编辑携带当前 revision 后成功递增版本，刷新显示新值。
- 同应用同渠道、同空间同渠道目标重复或平台错配被拒绝；目标不可被绑定到另一个应用。

### 场景：编辑冲突

- 两次使用相同 revision 更新时仅一个成功，另一个返回 409。
- Web 保留失败输入，提供刷新当前配置的入口；刷新不自动提交旧草稿。

### 场景：安全字段

- 凭据引用格式不符、路径、JSON 和未知字段被拒绝；界面不要求输入秘密。
- 仅保存引用时持续显示未预检和发布待实现，不调用真实商店。

## 需求：保护已有数据与运行边界

### 场景：历史项目与损坏数据

- 首次使用新功能不改写旧项目文件；新文件缺失时可正常开始。
- 新文件损坏、未知版本或绑定关系断裂时返回错误并保留原字节。

### 场景：导航与可访问性

- 从项目进入应用，刷新恢复项目／应用定位；浏览器后退不会显示其他项目的旧响应。
- 表单有可读标签、键盘可操作，失败保留输入，取消恢复触发按钮焦点；390px 窄屏无横向溢出。

### 场景：本地限制

- 新增接口同样受到本地 Host／Origin 和可信工作空间限制，hosted 仍拒绝启动，发布接口仍不可用。
