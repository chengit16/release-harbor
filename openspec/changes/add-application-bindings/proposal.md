# 应用身份与首批商店绑定

## 目的

落实第一期 P1-0 与 P1-1，使项目能够管理 Android／iOS 应用，以及华为／Apple 的商店目标和凭据引用，为后续产物核对提供稳定身份。

## 范围

- 创建、列表和查看应用；创建后平台与包身份不可编辑。
- 创建、查看和修改首批商店绑定，修改时进行版本冲突检查。
- 新增隔离且版本化的本地存储，不改写已有 `projects.json`。
- Web 的项目内应用管理、绑定表单、错误恢复与刷新定位。
- 合同、领域、API、存储和真实浏览器验收。
- 按用户追加要求，采用 Ant Design 优化现有项目、渠道能力和路线图页面，并写入前端规范。

## 非目标

产物上传、Profile 存储／验证、发布计划、执行器和商店操作不在此切片实现。保存凭据引用始终显示“未预检”；不创建发布成功或审核状态。
