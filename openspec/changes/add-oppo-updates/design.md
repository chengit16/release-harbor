# OPPO 接入设计

官方文档已于 2026-11-04 从开放平台的公开文档接口核对：10998（鉴权与签名）、10999（发布版本）、11003（文件上传）、11004（普通包详情）、11001（任务状态）。SDK 0.3.0 缺少定时设置、上传地址校验、严格资料与异步结果核对，因此由可信 provider 独立补齐，继续复用 SDK 安全存储。

Client ID／Client Secret 仅走本机配置向导。普通应用以包名定位，绑定目标必须与 Android 身份相同。准备只访问 token 与 app/info；提交执行前只查询一次详情，拒绝冻结、不在上架状态、非普通包和未明确可更新的状态。仅允许版本号递增。

准备从详情白名单投影公开资料及来源版本到预检和计划。联系人和 test_desc 不进入公开合同或内容摘要，在执行中复用该来源版本的本机商店响应；公开资料变更或缺失停止执行。未知字段（尤其 app_secret、server_secret、app_key）丢弃。资料来源由 worker 确认，浏览器不能声明。

立即映射 online_type=1；定时映射 online_type=2、sche_online_time，中国标准时间 yyyy-MM-dd HH:mm:ss。UTC 意图保持不变，界面注明商店时区。版本升级固定 version_type=2、cpu_code=0。先独立复核副本与 Profile，再获取上传配置，核对 HTTPS 平台地址，不允许重定向、本地地址或跨平台传递秘密。首次平台写入前持久化许可，上传响应 MD5 和大小须匹配，再提交版本。

app/upd 的 errno=0 且 data.success=true 仅代表任务受理。只读查询 task-state，匹配包名和构建号，task_state=2 才记录 OPPO 版本处理成功；1 保持平台处理中待核对，3 为处理失败待核对，缺失、超时等按安全固定诊断回报。许可后不重试写入。相同产物成功或待核对继续阻止重复提交，人工结论用提交语义。

计划文件升级版本 7，兼容旧事实和指纹。查询与页面刷新不发起商店写操作。自动化仅合成材料与隔离目录。
