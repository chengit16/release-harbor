# OPPO 工程验收记录

日期：2026-11-04。

## 实施范围

普通应用单 APK 递增更新，页面 Client ID／Client Secret、包名绑定、只读鉴权及资料复用、来源冻结、立即／定时发布、一次确认、独立副本检查与文件上传、MD5／大小校验、单次版本提交及异步任务核对。OPPO task_state=2 是版本处理成功，不表示审核通过或已上架。

公开资料从 worker 产生且必须匹配预检来源；测试说明、联系人、支付秘密均不进入公共合同。未知上传地址、资料缺失或变化、冻结和非普通应用默认拒绝。上传后状态不明继续阻止新计划，固定诊断保留，人工结论不重放授权。

## 隔离回归

新增 7 项 OPPO 集成测试，覆盖安全存储和目录、只读端点、敏感响应投影、状态及资料拒绝、立即／定时签名与时区、单次请求、异步处理中／失败／错配／超时、MD5 不符、无许可零写入、来源和版本校验、旧事实读取及未知结果阻塞、实际 APK 的完整 runner 路径。

Chrome 覆盖 OPPO 页面新增账号、账号自动选择、只读包名、实际合成 APK 检查、公开资料自动准备、摘要关闭不执行、一次明确确认、版本处理结果、刷新不派发、窄屏布局及秘密仅发送独立配置服务。保留既有华为、小米与 Apple 阻塞回归。

- 未安装 OpenSpec CLI，不宣称 CLI 校验通过。
