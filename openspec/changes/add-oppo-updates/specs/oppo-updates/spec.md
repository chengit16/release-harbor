# OPPO 普通应用更新需求

## 账号和身份

新增 OPPO 账号仅录入 Client ID／Client Secret；保留核对、重录、删除和关联保护。Android 绑定以包名定位，不接受其他平台或错误目标。

## 准备与确认

用户选安装包、更新说明和立即／定时上架后，系统自动只读检查、复用资料并形成摘要。关闭不执行，一次明确确认才消费授权。资料不完整、版本未递增或目标状态不允许时停止。

## 执行和恢复

独立副本再次核对；合法平台上传地址和 MD5 检查后才提交固定版本信息。异步受理不能冒充处理成功；任务包名与版本必须匹配。异常保存具体安全诊断，保持未知事实并阻止重复提交。重启不重放。
