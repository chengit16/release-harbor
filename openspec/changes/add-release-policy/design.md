# 设计

- 公共 releasePolicy 取 after_approval 或 scheduled；定时必须包含规范 UTC notBefore，时区在页面明确展示。选择表示审核通过后最早开放时点，不是延迟上传任务，不保证审核未完成时强制上线。
- 新建计划的策略进入完整快照与去重指纹；修改策略必须新准备。历史缺失策略不回填、不推测，不修改旧摘要。
- 准备、冻结、确认、许可及独立执行均拒绝已过去的定时时间；不存在客户端声明已同步商店的字段。
- 小米 after_approval 不传 onlineTime，scheduled 传 Unix 毫秒值。旧快照没有策略时保留历史可读，但不允许以未知上架设置新发起小米执行。
- Android／iOS 共用页面选项；华为当前仅保存草稿、Apple 暂缓的构建上传不设置审核版本上架策略，摘要明确说明未同步，不将选择显示为平台已生效。
- Apple 后续送审映射 AFTER_APPROVAL 或 SCHEDULED／earliestReleaseDate；本轮记录合同，保持当前上传执行阻塞，不发送版本修改接口。

- 小米名称、隐私政策、图标从固定官方公开上架页自动复用，认证查询名称与包名双重匹配，图标只读取固定官方 CDN 原图；不访问隐私站点、不跟随重定向。公开页及图片分别有字节上限，结构变化直接失败。来源和检查时间由 worker 生成，公开资料随预检及快照保存。
- 计划存储写版本 6，读版本 1–5，保留旧指纹和缺失策略；预检公开结果预算 512 KiB，含两份图标的私有发布输入预算 1 MiB。
