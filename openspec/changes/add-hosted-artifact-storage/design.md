# 在线产物交接设计

- 管理员与发布操作员可接收、继续、取消及下载本空间产物；查看者只读元数据；清理已接收原文件限管理员。每次操作核对当前成员和空间／项目／应用。浏览器不提供对象位置、上传 ID、ETag、对象版本或签发时限。
- 每包最多 256 MiB、每空间接收中及已接收合计 2 GiB；按 8 MiB 连续分片，最后一片可较小。创建在空间锁下预留配额；浏览器提交分片 SHA-256 清单，签发单片、固定长度、固定 SHA-256 的短时 PUT。继续时重新核对清单与实际已存分片；中断的当前分片由用户显式续传。刷新只读记录，重新选择相同文件即可继续，不持久化签名地址。
- 完成基于对象存储列出的实际片号、大小、SHA-256、ETag；条件完成不覆盖已有对象。再以固定版本读回大小与接收标记，才原子记录待检查。若完成已发生但回报中断，显式重试通过服务端生成的独占键及标记核对，不再次创建对象。客户端清单不充当可信全文件摘要。
- 下载只在显式请求下签发，绑定已冻结对象版本、HTTPS 和 2 分钟有效期。已签地址到期前可能仍有效；不将签名地址写入日志、浏览器存储或列表。清理仅删除冻结版本，不删除同键的其他版本。
- 24 小时后停止接收；独立回收处理过期分片和超过 30 天、无引用保护的已接收原文件。对象回收失败继续占配额。跨进程使用空间事务锁；后续执行器和计划须在同一锁下登记／释放引用保护。桶配置中断分片生命周期，处理创建时进程中断产生的孤立上传；不对整个产物前缀配置无条件到期删除。
