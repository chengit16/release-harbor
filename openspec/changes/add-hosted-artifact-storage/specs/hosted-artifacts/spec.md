# 在线安装包接收

## 新增需求：安装包可分片直传并续传

- 当具有写入权限的成员选定合法 APK，服务端按归属与真实剩余配额创建记录，并只为已登记的一个分片签发短期上传能力。
- 上传中断或刷新后，当成员重新选择分片摘要相同的包，系统只补传存储中缺少的分片。
- 当片号、长度、摘要或版本证据不匹配时，不能把记录标为待检查；同空间并发不得超额预留。

## 新增需求：完成与清理始终绑定真实对象

- 当存储列出匹配的完整分片、完成并读回确切对象版本，记录为待检查；清单不代表可信包身份或全文件 SHA-256。
- 当成员显式下载时，只签发当前授权范围内的指定对象版本；查看者和其他空间都不能签发。
- 当取消、过期或清理时，只处理本记录的上传或已冻结版本；存在引用保护或未核对的存储异常时，不释放保留的配额。
- GET、页面加载和刷新只读目录，不触发签发、续传、完成或对象删除。
