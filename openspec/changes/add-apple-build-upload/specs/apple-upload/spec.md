# Apple 上传规格

- 只有已确认、当前有效的 apple_upload_build 计划可显式执行，完整来源、归属和一次性消费继续生效。
- 缺少匹配工具或材料格式无效时不授予远端许可；不自动安装工具或另取账号。
- IPA 实际身份、版本、摘要和目标只读查询一致后才进入上传；目录或文件变化拒绝。
- 私钥临时文件受限于本次父进程运行目录，正常、失败及 worker 中断均清理；参数、日志及公开回执不含秘密。
- 单次 altool 上传，无命令 shell 插值、重试或工具回退。工具成功后仅对当前应用、营销版本、构建号及 IOS 版本关联查询一次，明确区分上传已接收、构建处理中及构建可用，不将查询失败或空列表当成可用；失败和中断遵守未知结果核对规则。
- Apple 人工结论与华为隔离；新结论不重放旧授权。页面保持 Ant Design 白色主题，桌面与窄屏均可核对具体动作。
- 自动测试只用合成 IPA 与密钥、隔离端口及进程替身；本轮不提交真实商店。

按用户最新纠正，iOS 发布方式为审核通过后自动发布或手动发布，不提供指定时间选项；新准备及冻结拒绝 iOS 定时／Android 手动策略，旧 iOS 定时快照只读保留且不可执行，须重新准备。选择随计划固定，本轮仅记录，后续送审时再同步 Apple。
