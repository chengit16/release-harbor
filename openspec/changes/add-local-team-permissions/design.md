# 设计

安装级账号目录以可选权限字段兼容 T1，缺省无权限。授权保存绑定完整指纹；配置更新后需重新授权。权限更新采用预期版本防止两个窗口互相覆盖，不随业务备份恢复。

HTTP 会话边界维持默认拒绝，显式放行资源读取及动作。列表在控制面按可信身份过滤；计划、尝试及批次通过保存的目标恢复归属，不依赖客户端提供绑定。业务内部在冻结和实际写许可前再次读取账号与授权。后台任务保留发起身份，停用、重置或撤权后不得继续取得写许可；已经发出的许可保留原事实，不声称撤回。

公开会话仅包含安全授权投影。Web 按菜单挂载页面，操作禁用只提供提示，服务端仍独立判定。审核成员不加载管理员跟踪、通知或维护入口。
