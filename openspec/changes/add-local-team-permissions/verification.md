# T2／T3 交付与验证

2026-11-11，本轮在原本机工作台接入成员授权及发布权限。不新增线上入口、数据库、域名或组织身份服务，沿用已有本机应用、账号引用和发布安全规则。

## 已交付行为

- 管理员通过「成员管理 → 成员授权」逐项配置菜单、应用渠道、缓存读取、官方查询、准备、确认执行与人工核对。Apple 上传、已有构建送审及手动发布独立选择。
- 成员列表由服务端过滤，直接 URL、上传和动作同样检查范围。应用配置为只读，账号维护、备份、本机设置、自动跟踪继续仅管理员使用。
- 单计划、Android 批次及 Apple 在准备、冻结、确认和实际写许可边界读取最新成员资格。批次任一目标越界时整次确认失败；排队后撤权不能取得后续写许可。
- 授权限定完整绑定指纹，改绑后须重新授权。列表及旧幂等请求不能把当前授权扩展到旧账号快照；旧计划、回执、未知结果及版本保护保留原事实。
- 退出、账号切换及权限代次变化清除模块级公开草稿和当前历史条目的草稿状态；会话失效时停止业务页面。

## 验证范围

所有测试使用临时目录、合成账号和受控 worker，不读取用户真实材料，也不向商店上传、送审或上线。已运行成员正常准备与一次确认、重复确认零重放、范围过滤、改绑后的旧记录隔离、单计划／批次／Apple 排队撤权等接口回归。

真实 Chrome 专项已通过管理员创建和授权、成员只读审核缓存、刷新零官方查询、同一文档切换账号清除草稿，以及 1440／375／844 视口。已人工查看桌面授权弹窗、375 手机弹窗与发布页截图，文字及操作可达；成员未获准的华为送审选项禁用。

开发中修正了退出后旧会话复验、模块草稿未清理及改绑后的旧响应范围问题，登记为 RH-0074、RH-0075。问题档案引用交付说明后，曾因说明文件尚未写入使资源复制测试失败；补齐文件后全量测试已重新通过。

## 后续范围

T4 将补齐操作者、授权变化、尝试及回执的审计关联，旧历史不补造身份。真实商店动作仍按具体账号、目标和版本独立验收；撤权不能撤回已发出的远端动作。

操作与更新步骤见[本机团队指南](../../../docs/guides/local-team.md)。已启用 T1 的安装停止旧服务后重新构建并启动即可，无须重新初始化管理员。
