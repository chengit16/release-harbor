# 执行设计

计划继续保持不可变，release-plans.json 升级为 schemaVersion 2，增加 attempts。读取兼容版本 1，写入时迁移。一次性确认与执行尝试关联在同文件原子提交；一份计划最多一次执行，重复执行请求返回原尝试，不重新派发。串行队列和全局单槽仅适用于当前单进程本地服务。

API 仅持有公开快照，启动固定 worker；任务通过有界私有 stdin，握手通过 nonce 关联 IPC。worker 重算指纹、检查期限、固定路径与产物身份，复制到本次独立目录后再次复核，读取账号前核对目录版本。商店鉴权和目标查询使用既有只读适配。

远端调用前 worker 请求许可，API 重新核对依赖并原子保存 running／remoteStartedAt 后才回复许可。保存不明不得回复。任何已记录远端开始的中断均标记 needs_reconciliation；未获许可的中断记为 interrupted。重启仅整理遗留状态，不重新执行。无跨进程自动恢复队列。

华为适配固定 draft、maxRetries:0，禁止送审、额外资产和自定义端点。SDK 回执仅在 worker 内存生成，不落入 SDK 默认目录；控制面只接受固定状态码和时间，不接收供应商消息、URL、路径或秘密。SDK 返回失败也可能发生了部分写入，统一待核对。成功只代表草稿保存，不代表送审或上线。

Apple 在消费授权前拒绝，保留计划。网络失败时前端只查询事实，禁止自动重放；已消费计划不可取消或再次确认。另一个新计划也不能绕过同一目标的待核对状态；需后续人工核对流程解除，当前保守阻止。
