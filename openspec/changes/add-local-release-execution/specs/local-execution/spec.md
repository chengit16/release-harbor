# 本机执行规格

## 授权与去重

- 仅 confirmed、当前有效且摘要一致的计划可消费；必须明确 acknowledged:true，精确本机 Origin 与专用请求头。
- 消费与尝试同文件保存；并发和重复请求只产生一个尝试。已消费计划不可取消、复活或再次派发。
- 单槽忙碌、Apple 兼容缺口、旧配置与超期均在消费前拒绝。

## 独立执行

- worker 再次验证计划指纹、授权、实际文件身份、摘要和账号版本，并只读核对商店目标。
- 未持久化远端开始标记前不得商店写入。超时、崩溃、回执丢失不能推断远端未执行。
- 重启恢复不重放，未知结果阻止同目标新执行。回执不包含秘密或本机路径。

## 页面

- 已确认计划提供明确执行按钮和二次确认，显示具体目标、产物与动作。
- 执行记录独立展示；刷新仅查询，可查看处理中、草稿已保存、执行前失败、中断、待核对。
- Apple 说明当前阻塞原因；上传、草稿、送审与上线不得混淆。
