# 在线身份与工作空间隔离

本机入口固定使用 `local`，通过隧道访问仍不提供登录。第五期先实现独立在线目录，让受邀成员能在浏览器管理自己空间的项目、Android 应用和华为商店绑定。

P5-0 定义边界与测试基线；P5-1 交付 OIDC 登录、服务端会话、管理员／发布操作员／查看者、成员管理和 PostgreSQL 目录。在线入口只在回环启动，经受控 HTTPS 访问。商店绑定只记录 appId 与凭据引用，不验证商店权限。

产物接收、执行器配对、商店查询或写入、公网试点及迁移本机数据由后续切片承担。详见[第五期规划](../../../docs/plans/phase-5-hosted-console-plan.md)。
