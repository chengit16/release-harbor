# 在线工作空间

## 新增需求：由受邀身份建立会话

系统必须根据已配置发行者的 OIDC 稳定身份匹配有效成员。登录回调须消费与浏览器绑定的一次性事务。

### 场景：受邀成员登录和退出

- 当成员完成可信发行者的登录，系统签发独立的服务端会话，返回可访问的工作空间。
- 当其退出或会话过期，原 Cookie 不能再访问在线业务接口。
- 当没有有效成员、登录事务缺失、已消费或已过期，系统不得建立会话。

## 新增需求：空间及角色由服务端核验

系统必须检查当前会话、空间成员关系和权限，再访问带完整归属的资源。

### 场景：两个空间的目录隔离

- 当成员切换工作空间，仅显示新空间目录，不回显旧空间请求结果。
- 当请求指向未授权空间、错误父级或其他空间的资源，拒绝读取和写入，不透露资源是否存在。
- 当管理员调整或撤销角色，下次请求按新权限执行；最后一个管理员不得被降级或撤销。
- 当管理员登记华为 Android 绑定，仅记录配置；不触发商店查询、上传、送审或执行。

## 新增需求：本机与在线入口独立

### 场景：运行在线目录

- 在线入口没有本机凭据、备份、安装包或发布接口；身份或数据库缺失时拒绝启动或拒绝请求。
- 本机入口保持固定空间与现有存储；将其设为 hosted 不会打开在线服务。
