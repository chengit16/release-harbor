# 设计

- 独立 NestJS／Fastify 装配和独立 Web 构建。在线服务不挂载本机模块，旧入口仍拒绝 `hosted`；生产入口只监听回环，经同源 HTTPS 转发，校验固定 Host。默认不部署转发。浏览器写请求需要精确 Origin 和操作标记。
- 信任预配置 HTTPS OIDC 发行者。使用授权码、S256 PKCE、随机 state 和 nonce；登录事务由随机 HttpOnly Cookie 绑定，在数据库短期保存且原子消费。校验 ID Token，按发行者和稳定 subject 识别受邀成员。没有有效成员关系不建立会话；不按邮箱或 IdP 自报角色授权。不保留 IdP token。
- 会话是随机不透明值，Cookie 使用 Secure、HttpOnly、SameSite=Lax 与 Host 约束，库中只保留摘要，最长八小时，不自动续期。登录换新会话、退出撤销当前会话。客户端不持有可读的身份令牌；服务端每次重新检查成员关系。
- 由维护 CLI 创建新工作空间和首个管理员，不能借重复初始化提升已有空间权限。管理员按已知 OIDC subject 预登记成员，可改角色或撤销，不能移除最后一个管理员。空间、角色及目录写入同事务重验，成员变更与目录写入按空间串行。操作者与查看者在本切片只读目录；发布能力待后续开放。
- 数据库存储在独立 schema，跨表用带工作空间的复合外键；项目、应用和绑定请求均限定完整父级归属。不同空间可复用业务标识；跨空间或错父级返回不存在。目录复用现有字段验证，仅允许 Android／华为目标；绑定配置不授予执行资格。
- 对象交接后续采用私有版本化 S3 兼容对象、256 MiB 单件上限。首轮验证基线建议每空间 2 GiB、未完成分片 24 小时回收、已接收对象 30 天留存且有引用或活动任务不得清理；供应商、区域与恢复目标在真实环境选定后核对。首轮执行器限定出站配对、只读准备优先；首次写许可外的独立恢复证据留 P5-4 实现。
