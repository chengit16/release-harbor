# 发布计划规格

## 冻结不可变快照

- 当前通过且未过期的预检可用于冻结单应用、单商店、单产物计划。跨项目、失效预检、未知动作、空说明及多余字段必须拒绝。
- 华为只允许保存草稿；Apple 只允许上传构建。冻结完成后修改说明或动作必须生成新计划。
- 相同幂等 ID 和内容重复冻结返回原计划；相同 ID 不同内容冲突。

## 复核与确认

- 页面显示应用、商店 App ID、安装包版本、账号引用、明确动作、完整说明和各类指纹；查看不会执行。
- 确认框要求明确勾选；关闭不产生授权。服务端拒绝缺少来源、未知字段、摘要不符和依赖已变化的确认。
- 并发确认只保留一个授权，重复确认不延长时限。取消后不能确认；取消授权不可恢复。

## 失效与恢复

- 字节、绑定或凭据目录变化、原预检过期及授权过期，分别显示原因和重新预检／冻结指引。
- 磁盘损坏拒绝写入；重启保留快照及确认／取消状态，不触发商店请求。
- 桌面和窄屏均可创建、复核、取消、查看历史；刷新恢复发布计划页签。
