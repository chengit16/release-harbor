# 设计与执行边界

## 账号及来源

两家使用各自 Client ID／Client Secret，页面材料走独立配置进程，API 不接触秘密。目标使用各自数字 App ID，同时按包名查询核对。魅族分页查询最多 100 页且核对总数与重复目标；读取确定版本详情，拒绝在审／未上架及已有待审修改。荣耀查询 appId、详情与当前发布流程；只接入已全网上架普通应用，拒绝未知、编辑中或等待发布的状态。

公开来源合同只保存魅族版本 ID／版本名／公开材料摘要，以及荣耀发布流程 ID／构建号／默认语言和允许复用的多语言资料。不记录联系人、测试账号、证件和原始详情。秘密不参与指纹。执行时查询同一来源并重新比对，私人必需字段仅在可信进程即时复用。

## 真实动作

魅族 SDK 只有暂存 APK；产品直接实现签名及 app/publish，复用官方 detail 对应公开资料与私人备案材料。返回新 verId 后只读核对该版本包名／应用 ID／版本名及在审状态，明确才记已提交。没有定时参数，准备、冻结与执行均拒绝 scheduled，不擅自跳过。

荣耀先获取上传对象、上传、绑定、复核绑定 APK 摘要及版本，再更新默认语言 newFeature（setAll=0），最后提交审核。其他文件和语种保持现有值。releaseType=1／2，定时携带明确 +0000 时区的 releaseTime。成功须有安全 releaseId，不把文件或草稿成功当作送审成功。上游 SDK 仅草稿不满足本次动作，因此集中在 provider 实现完整协议。

## 授权与恢复

所有可能创建远端状态的请求前，独立检查真实产物、来源、账号版本和有效期，并取得父进程持久化的一次性许可。任何许可后异常均待核对，不自动重试或撤回。读取固定 HTTPS 网关，禁止任意 URL／重定向，响应有界且只返回固定诊断。

schema9 扩展公开来源和两种结果，读取 1–8 不回填字段、不改旧摘要。未知结果继续阻塞重复目标，人工结论沿用送审语义。
