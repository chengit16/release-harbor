# 渠道更新要求

- 账号向导、编辑／核对和 Android 绑定须分别提供魅族与荣耀。
- 准备只读，严格核对归属、包名、来源与支持状态，不提供虚假默认资料。
- 用户只需选择安装包、更新说明及支持的发布类型；正常发布只确认一次。
- 魅族定时类型须明确禁用并在服务端拒绝，不发送未知参数或改成即时。
- 荣耀定时意图须冻结并映射有明确时区的 releaseTime；发布前到期须停止。
- 独立执行须重算计划／产物、复核来源并取得一次远端许可。写操作不重试。
- 明确送审回执前不得显示成功；错误／中断保留具体安全诊断，无法确定结果须人工核对。
- 旧记录可恢复，页面刷新和重复点击不得重放已消费授权。
