## 保护的行为

账号走独立录入、安全库及安全目录；数字 ID 与包名精确匹配；只读准备不发写请求。来源缺失、在审、类型错误、分页冲突、频率限制及鉴权错误不伪装成功，私人材料不进入来源或错误。

魅族验证完整公开签名、上传后发布、new verId 在审核对，定时在多层明确拒绝，含 32 位库的实际 APK 在远端许可前停止。荣耀验证完整对象／上传／绑定／摘要与版本复核／语言／审核链路，setAll=0 保留其他语种，定时发送带明确 +0000 的 UTC 值，恶意上传 URL 拒绝。

重复确认只创建一个尝试；任何许可后失败、超时、回执缺失保持待核对，无自动写重试。旧存储 schema1–8 原样读取，新增来源及回执保存为 schema9，不补字段或改旧摘要。

页面检查覆盖两家新增账号、数字 ID 绑定、自动资料复用、魅族定时禁用、荣耀定时准备、摘要关闭无上传、一次确认、刷新去重和窄屏。截图位于忽略的 artifacts 目录，不提交。

截图复核另发现新动作遗漏共用送审判定，已让摘要按钮复用统一判定，并新增两家未知结果、具体原因保留、送审结论和重提阻塞回归；最终 Chrome 已通过，并同时断言实际设置范围。
