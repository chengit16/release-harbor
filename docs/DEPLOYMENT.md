# 本地运行与后续在线部署

## 当前可运行方式

开发：pnpm dev，Web 在回环地址 5178，API 在回环地址 4399。构建后：pnpm build && pnpm start，通过 API 的 4399 端口提供静态 Web。

项目数据保存在用户目录 `.release-harbor/projects.json`，可通过 RELEASE_HARBOR_DATA_DIR 使用独立目录。单进程文件存储不支持多个 API 实例同时写入，原文件损坏时拒绝覆盖。

当前没有组织登录、会话或生产认证。API 仅监听 127.0.0.1，限制 Host 与 Origin，并拒绝 hosted 模式。项目创建可用不等于线上多租户安全能力已具备。

## 已指定隧道的来源兼容

当前工作台兼容用户已指定的 `https://6e03b6cd.r20.vip.cpolar.cn` 和 `https://13231goev5981.vicp.fun` 页面来源。`apps/api/src/workbench-origins.ts` 集中定义普通业务精确白名单，供全局请求保护、单渠道计划、批次、Apple 审核、状态查询、模板、跟踪及本机维护装配使用，避免页面能读列表却在业务入口返回 403。操作标记、摘要确认、一次性授权及归属校验继续执行。

隧道必须将上游 Host 保持为回环地址，API 仍只监听 `127.0.0.1`；不自动信任 `X-Forwarded-Host`、任意隧道子域或请求自身的 Origin。更换域名需要同步 API 的精确列表与 Vite 的 `allowedHosts`，并重启服务。来源白名单不提供登录或公网访问认证。

商店账号配置仍限定在服务所在电脑通过 `127.0.0.1`／`localhost` 打开的工作台：材料直接进入独立回环进程，普通业务 API 不转发秘密。通过隧道新增、重新录入、改名或删除账号时返回明确的本机操作提示；已配置账号仍可供发布流程使用。核对过程与接口范围见[来源修复验证](verification/workbench-origins-2026-11-10.md)。

安装包接收允许持续有进度的慢速传输，绝对总时限为一小时；连续两分钟没有完成字节写入则终止接收，清理不完整文件并保留失败记录。浏览器等待为一小时加五秒，之后仍需读取独立身份检查结果。单文件 256 MiB、存储预算及来源限制继续执行。代理或隧道自身的请求期限仍可能先中断连接，需按实际错误核对；本项目不自动重传。修改后开发 API 由 watch 加载，生产启动须重新构建 Web 并重启 API，页面刷新后获取新的客户端时限。详见[上传超时验证](verification/artifact-upload-timeout-2026-11-10.md)。

## 本机备份与后台任务

本机设置提供备份／恢复入口。备份按业务文件白名单生成未加密 JSON 容器，不含凭据秘密或安装包原文件，最大 32 MiB；建议另行下载保存到其他磁盘。同盘七份自动副本不能防磁盘损坏。具体范围见[操作指南](guides/local-efficiency.md)。

恢复使用 `.local/active.json` 选择完整业务代，原始数据代保留；账号配置仍指向原数据根。不要手工删除安装标识、活动指针和独立发布保护账本，不能用旧快照覆盖保护账本。跨安装恢复为只读历史，不自动转移发布资格。

每日自动备份和审核跟踪依赖 API 进程；关闭页面后可继续积累站内记录，关闭 API 或电脑休眠则暂停执行。重启／唤醒最多安排一次到期任务，不补齐所有错过周期。浏览器系统通知另外依赖页面运行与权限，不是常驻系统推送。仍只支持单个 API 实例写入同一数据根。

## 在线目标拓扑

1. Web 静态资源经 HTTPS 域名部署，可采用 CDN 或与 API 同源托管。
2. NestJS 控制面连接有事务和租户约束的数据库，承担会话、成员权限、配置引用、任务及记录。
3. 安装包通过受控上传进入对象存储，绑定大小、摘要和归属；不接受用户本机路径作为服务器文件地址。
4. 本地或专用执行器经配对认证后主动连接控制面，领取自己获授权的任务；需要时使用 macOS 执行器承担 Apple／Keychain 路径。
5. 凭据提供器按部署环境实现，秘密留在受信任执行侧，不随浏览器状态、公开配置或回执返回。

本机与在线模式复用领域合同，租户身份和任务授权必须由服务端决定。即使只对公司内网开放，也需完成身份与权限设计。

## 上线前交付门槛

- 登录、成员权限、租户范围、会话与写请求来源策略完成。
- 数据库迁移、备份恢复、对象归属与受控下载完成。
- 执行器身份、配对／撤销、任务租约、幂等处理与回执确认完成。
- 本地 Keychain 不被当作 Linux 无头凭据方案；替代执行环境须经真实验证。
- 公网操作只开放已验收渠道与动作；没有真实平台回读时保留待核对状态。

本轮不提供声称可生产部署的 Docker／公网启动配置，以免把尚无认证的基础 API 当成线上产品。具体托管商、域名、数据库和身份提供方留待在线阶段选择。
