# 魅族与荣耀更新指南

两家已完成已有普通应用的单 APK 更新工程接入，真实商店后台验证待用户操作。保持“选择安装包和资料 → 准备发布 → 核对摘要确认一次 → 查看结果”。

## 账号与绑定

- 魅族：在魅族开发者中心创建客户端凭据，获取 Client ID／Client Secret。
- 荣耀：在荣耀开发者服务平台开通 API 传包并创建客户端凭据，获取 Client ID／Client Secret；与华为账号材料分开，不使用应用 SecretKey。

在“商店账号”新增对应渠道，页面保存后可复用、编辑名称、重新核对或重新录入。随后进入 Android 应用的商店绑定，分别填写对应商店的数字 App ID 并选择账号；系统仍会按包名查询并验证 ID 归属，不能仅填写任意数字。

## 日常发布

选择检查通过的新 APK，填写更新说明，选择支持的上架类型后点击“准备发布”。名称、介绍、图标、资质及其他既有资料自动沿用，不重复填写。缺少必需资料、存在在审／编辑／待发布流程时，先在商店后台处理。

魅族只接受不含 32 位库的新版本 APK。当前公开 API 没有定时参数，“指定时间上架”明确禁用；若从其他渠道带入了定时选择，需要明确改选立即，不会自动改动你的意图。提交会完成文件上传和新版本发布，并核对新 verId；不是只暂存文件。

荣耀支持审核后立即上架和指定未来时间。界面使用设备时区，快照保存 UTC，提交发送明确时区。系统上传、绑定安装包，确认 SHA 与版本一致后只修改默认语种更新说明，其他语言及资料保留，再提交审核。更新说明最多 500 字。

准备完成会打开发布摘要；关闭不会上传。核对目标、账号、版本、说明、来源和时间后，勾选并点击一次“确认提交审核”。结果“已提交审核”不代表过审或已上架，请在对应后台核对。

## 失败与待核对

未取得许可的失败显示未上传，可按具体建议修正并重新准备。许可后遇到断网、HTTP 错误、业务拒绝或回执不符，保留“待核对”，系统不重试，也不把本地停止当成撤回。

魅族提示缺少“推荐语”时，到魅族后台维护该资料；即使旧版本已上架，当前发布接口仍要求这一项。若修改触发资料审核，先等该流程完成再重新准备，无需因此重建账号或重复上传。明确的同版本替换／资料修改待审会单独提示，不能跳过。[诊断与兼容说明](../verification/meizu-target-diagnostics-2026-11-05.md)。

到后台核对同一应用、包名、版本、审核及处理中任务，然后在原执行记录登记真实人工结论。仅在确认未提交且无处理中任务后，才重新准备；原计划授权不可重用。

## 第三期荣耀状态观察

已执行荣耀版本可从发布摘要或执行详情点击“查询荣耀状态”，无需再确认上传。查询只针对本次版本名和构建号；审核通过与已上架分别核对，查询失败不覆盖旧回执。操作及限制见[状态查询指南](release-status-observations.md)。当前查询为对应版本的当前流程观察，不冒充原历史审核单查询；魅族状态查询需要可靠版本锚点后另行接入。
