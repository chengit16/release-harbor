# 商店审核状态查询

第三期已启动，支持荣耀 Android 已执行版本及魅族新提交的确定版本。已有 Apple 状态刷新继续从其审核工作区使用；其余渠道按官方能力逐家接入。

## 在哪里操作

1. 点击左侧“发布 → 审核状态”，与“发布中心”并列独立访问。
2. 按项目、应用、渠道、审核状态或待处理项筛选。列表按已执行的送审目标展示版本、已有观察及查询时间；未获取状态不等于审核中。
3. 点击“查看详情”。荣耀／魅族记录在详情中点击对应的“查询荣耀状态”／“查询魅族状态”，等待查询结果。该按钮只读查询，不上传、送审、上线或重试原执行。
4. 核对版本、构建号、来源与时间，查看失败建议和历史。关闭详情后列表重新读取本机记录，反映新观察。

手机端按卡片完整显示版本、状态、查询时间和待办；桌面为可分页表格。

也可从发布摘要、执行详情或 Apple 已有操作记录点击“查看审核状态”，带上当前应用和记录定位。发布详情不再嵌入查询面板。筛选与详情保存在 URL，支持刷新及浏览器前后退，均不重复查询商店。

已保存的 Apple 观察在菜单中只读展示；需要更新 Apple 目录或执行手动发布时，点击“查看发布记录”回到已有发布流程。其他未接入查询的渠道如实提示，不能根据原回执推断审核状态。

## 为什么列表没有数据

列表和顶部统计都受当前筛选影响。先点击“重置审核筛选”查看当前本机全部记录，再到发布中心核对是否存在该渠道的已执行送审记录。

当前菜单汇总工作台本机保存的执行记录，不会因为绑定商店账号而自动导入商店后台已有版本。仅配置绑定、准备发布、未取得远端写入许可的失败、保存草稿及上传构建，均不会生成 Android 送审跟踪记录。列表为空不能说明商店后台没有应用或版本，也不表示审核失败。

魅族旧送审记录缺少版本 ID 时仍会列出，只是无法自动查询；当前数据目录根本没有该渠道执行记录时才不会出现对应行。无需为了让列表出现数据而重新提交已在商店处理的版本。若原记录保存在另一台机器或另一数据目录，应先核对原工作台数据来源。

## 如何理解结果

- **审核中**：荣耀当前流程的版本名和构建号均匹配本次计划；魅族的原送审版本锚点与详情身份匹配且状态为待审／在审。
- **审核通过**：审核已通过；不据此显示已经上架，请到后台核对后续发布。
- **审核未通过**：到对应商店后台查看具体意见并完善资料。工作台不保存或展示私人审核文本和附件。
- **已上架**：荣耀已上架版本信息完整匹配本次计划，或魅族确定版本详情在身份匹配后明确标为上架。
- **已下架**：魅族原送审版本已被标为下架，到后台核对后续安排。
- **尚无法确认**：平台返回其他版本、未知状态或查询失败。保留原执行回执，不把旧上架版本或原提交受理当本次成功。

首批查询荣耀“当前流程”，未取得原历史审核单锚点时不代表精确查询当时的原单。当前流程已换为其他版本时会提示版本不匹配。

## 失败、重读与查询间隔

“重读本机观察”仅读取已保存记录，不请求商店。查询失败时检查账号权限或网络，保留上一条成功观察；不要据此重复提交应用。

成功查询后同一商店目标三小时内不重复请求；失败一分钟后可再明确点击查询。界面显示下次可查询时间，到时重读本机观察可更新按钮。该间隔是本产品的保守策略，非宣称 GET 接口具有相同的官方硬限制。已取得审核未通过或已上架结论时复用原观察，不再重复查询。审核通过但尚未取得上架证据时，可在间隔结束后继续显式核对上架情况；多渠道集中跟踪属于下一切片。

查询中关闭页面只停止浏览器等待；服务完成后会保存观察。重新进入先读历史。若服务在查询期间停止，未完成预约保留以避免频繁重查，系统不会自动续跑；再次点击时会提示该目标下次可查询时间。

## 其他渠道

小米官方暂未开放审核状态查询，现有接口只提供最新推送包信息与更新许可。因此小米继续显示真实提交回执及人工核对，不提供虚假的审核刷新。魅族新提交已支持确定版本查询；OPPO 已核对指定构建号的详情读取能力，完整审核状态字典仍待确认，尚未开放查询按钮。其他渠道具体进度见[第三期计划](../plans/phase-3-review-tracking-plan.md)。

本轮工程验证只用隔离目录、合成资料和替身网络，真实商店查询须由用户在具体版本点击后核对。

## 魅族版本查询

新提交会自动保存核对过的魅族送审版本 ID。在“审核状态”中选择魅族记录，点击“查询魅族状态”，可以查看待审／在审、不通过、已上架及已下架。来源和查询时间分别标记，结果不是实时推送。详情提示构建关联来自原执行，魅族详情没有独立构建号可再次核对。

旧记录未保存版本 ID 时，请到魅族后台核对该版本，无需重新提交。系统不按版本名猜测或取最新列表项，也不提供手填版本 ID 覆盖历史。查询错误保留原成功观察和原执行回执，不能自动解除待核对保护。

成功查询保守间隔三小时，失败一分钟后可显式再查；这是产品策略，不表示官方硬限额。已取得审核未通过或已上架结论时复用观察；后续商店操作仍到后台核对。工程与兼容说明见[魅族接入验收](../verification/meizu-status-observations-2026-11-06.md)。
