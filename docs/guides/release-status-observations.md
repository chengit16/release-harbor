# 商店审核状态查询

第三期已启动，首批支持荣耀 Android 已执行版本。已有 Apple 状态刷新继续从其审核工作区使用；其余渠道按官方能力逐家接入。

## 在哪里操作

1. 进入“发布中心”，找到荣耀的单渠道计划，点击“查看详情”；也可从执行记录打开“执行记录详情”。批次中的荣耀可从对应执行记录进入。
2. 执行结束且有远端写入许可事实时，详情显示“商店状态观察”。页面只读取本机历史，不自动查询商店。
3. 点击“查询荣耀状态”，等待查询完成。该按钮只读查询，不会上传、送审、上线或重试原执行。
4. 核对版本名、构建号、状态、来源与查询时间。查询时间表示当时的观察，不能当实时状态。

## 如何理解结果

- **审核中**：荣耀当前流程的版本名和构建号均匹配本次计划。
- **审核通过**：审核已通过；不据此显示已经上架，请到后台核对后续发布。
- **审核未通过**：到荣耀后台查看具体意见并完善资料。工作台不保存或展示私人审核文本和附件。
- **已上架**：荣耀已上架版本信息中的版本名、构建号、包名及 App ID 均匹配本次计划。
- **尚无法确认**：平台返回其他版本、未知状态或查询失败。保留原执行回执，不把旧上架版本或原提交受理当本次成功。

首批查询荣耀“当前流程”，未取得原历史审核单锚点时不代表精确查询当时的原单。当前流程已换为其他版本时会提示版本不匹配。

## 失败、重读与查询间隔

“重读本机观察”仅读取已保存记录，不请求商店。查询失败时检查账号权限或网络，保留上一条成功观察；不要据此重复提交应用。

成功查询后同一商店目标三小时内不重复请求；失败一分钟后可再明确点击查询。界面显示下次可查询时间，到时重读本机观察可更新按钮。该间隔是本产品的保守策略，非宣称 GET 接口具有相同的官方硬限制。已取得审核未通过或已上架结论时复用原观察，不再重复查询。审核通过但尚未取得上架证据时，可在间隔结束后继续显式核对上架情况；多渠道集中跟踪属于下一切片。

查询中关闭页面只停止浏览器等待；服务完成后会保存观察。重新进入先读历史。若服务在查询期间停止，未完成预约保留以避免频繁重查，系统不会自动续跑；再次点击时会提示该目标下次可查询时间。

## 其他渠道

小米官方暂未开放审核状态查询，现有接口只提供最新推送包信息与更新许可。因此小米继续显示真实提交回执及人工核对，不提供虚假的审核刷新。魅族等渠道需可靠版本锚点后再接入，具体进度见[第三期计划](../plans/phase-3-review-tracking-plan.md)。

本轮工程验证只用隔离目录、合成资料和替身网络，真实商店查询须由用户在具体版本点击后核对。
