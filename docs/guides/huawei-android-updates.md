# 华为 AppGallery Android 更新送审

**更新日期：**2026-11-07。第四期 P4-1 工程接入；新增正式送审尚待真实账号验收。

## 操作入口

进入“发布中心”，选择 Android 应用和华为 AppGallery 绑定。在单渠道发布表单中选择发布动作：

- **保存草稿**：默认选项，沿用原流程；不会提交审核，上架选择仅记录意图。
- **提交审核**：更新已有应用的单个 APK，写入默认语言的更新说明，等待至少两分钟解析后提交审核。名称、图标、截图和隐私政策沿用后台。

选择检查通过且构建号递增的 APK，填写最多 1000 字的更新说明，选择审核通过后立即上架或指定时间，再点击“准备发布”。系统只读核对来源并生成摘要；检查通过不会上传。核对摘要中的应用、商店 ID、来源版本、默认语言、新包版本和上架策略，勾选同意后点击“确认提交审核”。只需这一次确认，解析等待由执行器完成，不需要再到终端操作。

正式更新首版只接受全网已上架应用。后台已有草稿、在审、待发布或拒绝后编辑中的版本时，先在官方后台核对并处理，再重新准备；本入口不覆盖已有编辑、不创建新应用、不撤审、不自动续跑中断操作。非中国大陆开发者若需要额外上传分发参数，当前应在官方后台处理，本版未配置该参数。

## 发布策略与结果

立即上架在官方 v2 送审请求中省略 `releaseTime`；指定时间转换为明确 UTC 偏移格式发送。时间是审核通过后的最早上架意图，不是预约开始上传。等待解析期间时间过期或账号改变会停止后续送审并提示核对。

只有成功送审回执及同一版本／构建的审核中回读都匹配，才显示“华为已受理版本审核提交”。受理不表示审核通过、定时已生效或已上架；后续在“审核状态 → 商店状态”显式查询，并核对当前流程与在架版本。暂未接入华为按原执行定位的历史观察，独立查询不依赖发布记录。

上传之后的超时、网络失败、解析未匹配或送审回读未匹配都保留“待核对”，不自动重试。请在官方后台核对本次版本、构建和审核记录，再按页面填写人工核对结论；结论不恢复旧授权。不要因界面未显示受理就重新上传。

多渠道批次的华为目标仍是“保存草稿”，不会因为新增单渠道选项而隐式变成送审。正式送审当前从单渠道入口发起。

## 兼容与验证

计划写入 schema16，兼容读取 schema1–15。旧草稿、旧计划指纹、审核记录及授权保持原值；仅读取不会迁移文件或触发商店请求。升级后产生的 schema16 文件不可直接交给只识别旧格式的程序；停止服务后备份数据目录，再使用兼容版本恢复。

工程测试只使用合成产物、内存凭据和替身网络，不代表真实商店验收。实际验收需核对账号具备发布权限、目标应用资料完整、包签名与构建递增、默认语言说明、立即／定时参数，以及后台对应版本的审核受理结果。官方依据和验证记录见[本轮核对](../verification/huawei-android-submit-2026-11-07.md)。
