# 本机空间、任务与发布配置复用

## 安装包与备份清理

进入“本机设置 → 存储管理”查看全局安装包占用、2 GiB 预算、磁盘可用和备份占用。按应用、状态、七天／三十天以前及文件名／版本筛选；需要的原文件先下载，再选择清理。应用管理的安装包页也有同一下载与清理面板，限定当前应用。

确认框列出原文件数量、字节量与历史引用。清理仅回收原文件，身份、版本、摘要、发布历史和防重复保护保留；旧计划可能失效，重新发布需重新导入并准备。备份不含安装包原文件，不能从业务备份恢复被清理字节。准备、检查或执行中请等待结束，不要手工删除目录。

失败或已清理的记录可点击“删除记录”，详情卡片与存储列表均提供入口，也可勾选后点击“删除所选记录”。确认后独立安装包记录与残余文件一起删除，刷新或重启后不再显示。被历史计划引用的记录同样允许删除，计划快照中的身份、摘要、发布历史、回执和防重复保护继续保留；删除不会恢复旧计划或授权。工作台读取及其他安装包的上传、检查和发布不会阻止删除；备份恢复等独占维护期间请稍后再操作。所选记录本身正在接收或检查时不能删除，可用项须先清理原文件，混选时批量删除不可用。删除异常后关闭提示并刷新核对，不自动重试。

“备份与恢复 → 备份记录”显示总数量与占用，可勾选副本批量删除。自动备份仍保留最近七份，手动副本不会自动删除；已下载到其他磁盘的副本不受删除影响。清理中遇到 IO 错误，应刷新核对实际结果，不将批量操作理解为跨文件全有或全无。

## 跟踪任务

进入“审核状态 → 跟踪任务”集中查看跟踪中、暂停和结束任务，按状态及应用／渠道关键词筛选，保留已有项目／应用／渠道 URL 筛选。列表说明目标版本、结束条件、间隔、失败次数、最近／下次／到期时间及暂停原因。可暂停、继续、结束或前往官方版本详情；开启仍在商店详情中明确选择范围。

电脑休眠或退出服务时不运行。应用级观察不是指定新包的审核证明；小米仅公开在架，应用宝审核无版本身份等限制继续生效。账号或绑定变化需结束旧任务，重新核对后创建，不用“继续”静默更换目标。GET、刷新和导航不请求商店。

## 常用模板与历史配置

在发布中心的单渠道配置表单展开“复用配置与常用模板”；批次配置表单暂不显示此入口。选择来源后点击带入并确认覆盖，或者填写模板名称保存当前渠道、说明和发布偏好。模板按应用和发布方式隔离；历史只读，用户模板可删除。

带入后原安装包和具体时间被清空，必须重新选择。定时只保存偏好，不能带入过去时刻。模板没有预检、摘要、账号材料或授权，仍须准备并确认一次。来源读取或保存失败保留当前草稿；旧绑定不可用时不覆盖草稿。

Apple IPA 上传的发布偏好仍只记录意图，不设置商店版本策略；已有构建审核／手动发布继续独立流程，不能用上传模板替代审核动作。

## 运行诊断与通知测试

“本机设置 → 运行诊断”查看 API、恢复保护、跟踪、备份、容量和固定检查工具。提示提供前往存储、备份、跟踪的处理入口。工具可执行性存在不表示某个包解析通过，也不表示商店账号有上传权限。

先在通知设置明确开启并授权，再点“发送测试通知”。页面提示仅表示浏览器尝试展示，仍需检查操作系统通知中心与勿扰状态；这条测试不是商店变化事件。服务停止时页面无法取得诊断结果，请按首页启动项目。真实送审与通知投递按[验收清单](../verification/local-productivity-acceptance-2026-11-08.md)登记。
