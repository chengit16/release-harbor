# 应用宝与华为鸿蒙更新

## 应用宝

1. 到“商店账号 → 新增商店账号”选择“腾讯应用宝”，配置开通 API 传包的主账号 User ID 和 Access Secret。不要填 QQ 密码、推送密钥或将 App ID 填入账号字段。
2. 打开已有 Android 应用，在“商店绑定”添加应用宝，填写后台数字 App ID 并选择账号；APK 包名必须与该商店应用一致。
3. 接入新的单 APK，版本号须高于来源版本。名称、图标、隐私政策、测试登录材料等沿用商店资料，日常不重复填写。
4. 在“发布中心”选择渠道、安装包、更新说明和立即／指定时间上架，点击“准备发布”。更新说明不支持 Emoji。
5. 核对摘要后勾选并点击“确认提交审核”。这会上传并送审，不是草稿保存。受理成功只显示“已提交审核”，最终结果以商店后台为准。

当前只支持已上架普通软件更新，不支持首发、游戏或双包。只有一个实际为 64 位的包时使用 64 位上传字段，通用包使用普通字段，不伪造两个文件。

## 华为鸿蒙

1. 新建平台应用时选择 **HarmonyOS**，登记正式应用的 Bundle Name。不要复用华为 Android 应用身份。
2. 新增“华为鸿蒙”账号，填写 AppGallery Connect 中有该应用权限的 API 客户端 Client ID／Client Secret；本轮不支持 Service Account JSON。
3. 添加鸿蒙商店绑定，填写该 HarmonyOS 应用的数字 App ID，与 Bundle Name 分开。
4. 在“安装包”接入 DevEco Studio 导出的正式 **.app**，不是 .hap、.apk 或源码。沿用本机 256 MiB 产物限制。
5. 选择新版本 APP、更新说明（最多 1000 字）、立即／指定时间上架，准备并核对摘要，确认一次后执行。

执行会分片上传、关联软件包、核对解析及本次版本、更新默认语言的新版本说明，并按官方要求等待至少两分钟后提交审核。等待期间不要重复发起；已有资料在商店后台维护。此入口执行完整送审；华为 Android 单渠道另可选择草稿或正式送审，批次仍保存草稿，两种平台及授权互不替代。

## 失败与核对

准备失败表示本次尚未上传，可按具体建议修正后重新准备。执行前失败也未获远端许可，但旧确认不可复用。

出现“待核对”时，到对应商店核对目标 App ID、包名／Bundle Name、新版本、上传软件包和审核／处理中记录。鸿蒙解析失败需在后台查看包校验结果；解析中则继续等待后台处理。不能仅因暂未在审核列表看到版本就认定没有上传。明确核对后在执行详情记录人工结论，原事实不改写；系统不会自动重试送审。

本轮工程和隔离浏览器验证不代替真实渠道验收。详见[接口核对与范围](../verification/tencent-harmony-baseline-2026-11-05.md)。

## 第四期策略核对

应用宝按Unix秒时间戳发送；鸿蒙指定时间按UTC偏移发送，立即则显式发送过去时间以防继承旧定时。秒级时刻向后取整，不早于确认的计划时间。受理不证明定时已生效；请按[统一操作指南](release-orchestration.md)核对资料语言与实际后台时间。
