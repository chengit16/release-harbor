# 本机备份、跟踪与通知

本页说明本机效率增强的日常操作。功能由 Release Harbor API 进程提供；服务关闭或电脑休眠时，自动备份和审核跟踪不会执行。

## 备份与恢复

进入“配置 → 本机设置 → 备份与恢复”，点击“创建备份”后，可在备份记录中下载 JSON 文件并另存到其他磁盘。备份包含项目、应用、商店绑定、发布计划与执行历史、查询缓存、有限账号目录元数据、产物身份摘要以及本机跟踪和通知状态。

备份未加密，可能包含应用名称、版本和发布说明等业务信息。它不含凭据秘密、Keychain/Vault、配置会话、安装包原文件或原始日志。文件 SHA-256 用于检查损坏，不证明文件来源。容器最大为 32 MiB；建议下载后另行妥善保存。

恢复时选择 JSON 文件，先阅读预览中的覆盖范围和账号／安装包元数据数量，再明确确认。恢复会在同一磁盘保存当前快照，并切换到完整数据代；服务将短暂重启，页面刷新后继续使用。恢复后旧计划及授权不可复用，跟踪暂停、自动备份关闭，账号配置会话重新打开。跨安装导入只恢复可查看的业务历史，不获得发布资格；安装包缺失时需重新导入检查，凭据需在本机账号配置中重新维护。

如果存储损坏、保护账本缺失或恢复校验失败，服务会拒绝覆盖。不要删除 `.local` 保护文件或自行把旧目录复制到活动数据路径；应保留现场数据并先处理存储诊断。

## 每日自动备份

“每日自动备份”默认关闭。开启后，API 运行时最多每 24 小时创建一次，保留最近七份自动备份；手动备份不会被自动清理。服务退出或休眠时不会补齐所有错过的周期，恢复运行后最多补一次。失败会记录原因类别并生成站内通知，不会删除旧的成功备份。

自动备份和手动备份保存在同一数据盘，不能防止磁盘损坏。请定期下载一份至其他磁盘。备份与恢复要求没有发布、准备、上传、导入、查询或账号配置活动；有活动时等待完成后重试。

## 审核自动跟踪

在“发布 → 审核状态 → 商店状态”打开某个绑定详情，可显式开启只读跟踪。可选官方版本 ID、支持渠道的应用级观察、15/30/60 分钟间隔和跟踪到审核结果或继续到确认上架。默认七天到期。没有版本身份的结果不会被描述为某个新包状态。

服务每轮只查询一个到期目标，并与手动查询共享查询预约及全局并发限制。网络失败有限退避，三次连续失败暂停；身份或权限错误会要求处理。绑定或账号版本变化后任务暂停，不会偷换目标。恢复业务数据后所有导入任务暂停，需核对后显式继续。

渠道范围受官方接口限制：小米只观察公开在架版本，不提供审核进度；应用宝审核结果是应用级结果，官方未返回版本 ID，不能证明被跟踪的新包审核状态。其他渠道只有在官方响应身份足够时才作版本级比较。目录暂时缺少某项不会被推断为下架。审核拒绝原因和待手动发布等事件会标注观察时间，完整处理仍需进入商店后台。

## 通知

站内通知可从页头“通知”及“本机设置 → 通知设置与记录”查看。未读、已读只反映提醒状态，不表示商店事项已解决。通知最多保留最近 300 条；重启后不会把旧消息重复弹出。

浏览器通知默认关闭。只有在设置页明确开启并获浏览器授权后，新事件才会尝试显示；拒绝授权时站内记录仍可用。可另行选择是否在系统通知中显示应用名称。浏览器通知依赖页面运行，不是关闭浏览器后的系统推送服务。

真实渠道状态变化、渠道账号权限、无人值守运行及浏览器系统推送应分别验收；本地合成测试不代表这些远端条件已经验证。
