# 小米已有应用更新使用说明

当前支持小米中国应用商店已公开上架应用的单 APK 更新。动作是提交审核；真实提交及上架行为仍需用户对具体版本确认后核对商店后台，工程测试不作为真实受理证据。

## 初次配置

1. 在小米开发者平台管理中心打开“自动发布接口”，准备开发者邮箱、API 访问密码及平台 RSA 公钥／证书内容。“私钥”标签表示 API 访问密码，不是小米登录密码或 Apple `.p8`。
2. 工作台“商店账号 → 新增商店账号”选择小米，填写材料并选择审核测试方式，说明功能入口与体验路径。需要登录时填写审核测试账号或固定测试验证码，不用编写 JSON。
3. 不同应用的测试材料不同时分别建档。在 Android 应用添加小米绑定，目标包名自动使用当前应用身份，无需数字 App ID；选择账号后保存。

秘密仅经独立本机配置进程安全保存，不进入普通 API、公开计划、日志或浏览器存储。编辑名称不修改引用，调整材料使用“重新录入”。

## 日常更新

1. 上传并检查已有单 APK。
2. “发布计划”选择小米绑定和安装包，填写更新说明；名称、隐私政策、图标不再手工填写。
3. 选择上架类型：“审核通过后立即上架”或“指定时间上架”。定时需选择未来日期时间，页面显示设备时区。
4. 点击“准备发布”。系统鉴权、核对包名和更新许可，再读取小米公开详情页及官方 CDN 原图，自动复用现有名称、隐私政策及图标。后台名称与公开名称不一致、页面结构无法识别、图标无法安全读取时停止准备，不提交空值或占位图。
5. 核对摘要里的实际动作、版本、上架类型、资料来源与复用资料，勾选后点击一次“确认提交审核”。关闭摘要不会上传。

指定时间表示确认后立即上传送审，上架不早于指定时刻且必须先通过审核，实际可见时间由平台处理决定；它不是预约某个时间才上传。立即模式不设置延期时间，定时模式向小米发送 `onlineTime` 的 Unix 毫秒值。两种设置的真实平台结果均需首次验收。

自动资料来源为本账号应用的**公开上架版本**，不是未公开的后台草稿。接口仍要求资料时由系统随快照发送，不假定字段省略一定能保留后台资料。图标当前上限 256 KiB、边长 2048px；超过范围会停止准备。隐私政策仅读取公开链接，不访问或抓取第三方隐私网站。

## 失败与结果不明

计划历史和执行记录直接显示实际结果。“提交前失败 · 未上传”表示没有取得远端写入许可，小米后台不会出现此次提交；“已提交审核”才表示取得明确的受理回执。授权曾被消费不代表商店成功。可在摘要点击“查看执行原因”。

准备失败按原页原因处理后重新准备。只读查询触发频率限制时会单独提示，稍后重新准备；不要重用已消费的旧授权。若应用未公开上架、资料未公开或公开名称与后台不一致，请先处理平台资料；系统不会编造内容。账号、绑定、文件或上架时间变更均需新准备，时间已过去不能降级立即上架。

获写入许可后超时、中断或回执不明，保留待核对并阻止同目标再次提交。到小米后台核对版本及审核／上传任务，再记录“审核提交记录已存在”或“未提交且无任何处理中任务”，原始未知状态不改写、旧授权不恢复。成功或人工确认已有提交后，相同安装包不能通过新计划重复送审。

## Android／iOS 一致的选项

上架类型采用跨平台统一合同并显示在摘要。华为当前动作只保存草稿，上架意图仅记录在计划，没有设置商店送审后的发布方式。iOS 也可选择并保存意图，但 Apple 执行继续暂缓，仅上传构建也不能替代 App Store 审核版本的发布设置；后续送审适配再同步对应平台。

## 存储兼容及范围

计划文件读取版本 1–5，写版本 6。旧快照、指纹及时间不回填；未记录上架类型的旧小米计划应重新准备，不能默认为新授权。停止服务后可备份整个数据目录；降级应恢复升级前备份，不手改版本号。

当前不支持新应用创建、双包、自动审核状态查询或绕过审核强制上线。测试材料页面支持一个账号，维护 CLI 可导入官方多账号结构。上架策略不开放尚未接入的其他商店或暂缓的 Apple 执行。

依据：[小米自动发布接口](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=1134)、[Apple 版本发布选项](https://developer.apple.com/help/app-store-connect/manage-your-apps-availability/select-an-app-store-version-release-option/)。
