# 本机日常使用优化实施记录

日期：2026-11-08。用户授权将整体盘点建议一起落地；本轮不启动在线控制台或团队自动化，不代替真实商店操作。

## 范围与验收

| 工作包        | 实现                                                                                 | 验收重点                                                             |
| ------------- | ------------------------------------------------------------------------------------ | -------------------------------------------------------------------- |
| U1 空间管理   | 全局容量、应用／状态／时间／关键词筛选、受控下载、单项／批量回收原文件；备份批量删除 | 拒绝活动期清理，保留元数据、历史与版本防重；下载核对实际摘要         |
| U2 跟踪任务   | 审核状态独立页签，状态数量、搜索筛选、版本／间隔／最近与下次时间、暂停原因与启停     | 刷新只读缓存，不创建商店写许可；暂停／继续仍沿用原目标指纹           |
| U3 配置复用   | 单渠道／批次读取历史、保存常用模板、确认带入、删除模板                               | 字段白名单；不保存安装包、账号、具体时间、检查与授权；重新选包和时间 |
| U4 本机诊断   | 服务、恢复保护、容量、备份、跟踪、检查工具和浏览器测试通知                           | 本机事实与远端权限分开，失败给出具体入口                             |
| U5 文档与验收 | 当前首页整合、历史归档、领域／架构／指南／路线图同步、逐渠道待验清单                 | 现行事实和历史切片分开，不补造远端结果                               |

## 存储和并发

沿用现有产物 schema1，用户清理以 failed／removed 保存不可用原因和既有身份，先写事实再删字节；重启继续清除 failed 字节。历史发布快照不改写，旧计划通过现有有效性检查失效。实际下载从受控文件打开并验证大小和摘要，不接受路径。

清理与备份删除共用 LocalMaintenance，备份恢复、已有 HTTP 和只读调度不会并行侵入维护区。产物清理还核对持久化发布、准备、预检、导入和查询是否活动。批量先检查全部目标，IO 中途失败如实报错并刷新事实，不宣称跨文件事务。

新增 `release-presets.json` schema1，有界一百份模板、严格合同和单进程原子写队列。加入备份白名单及跨模块归属校验；旧备份不含文件仍兼容。历史来源只读投影，不迁移旧授权。跨应用模板拒绝，失效绑定应用前拒绝覆盖草稿。

## 交付边界

自动备份仍固定保留七份，手动副本由用户选择删除；没有增加任意路径或自动清理成功安装包。应用级审核精度、官方查询局限与同机运行条件不因本轮优化改变。已存在的真实历史结果不明继续保留；新验收清单供下次实际发版追加，不要求重复送审。
