# 成员管理与应用授权交付核对

## 交付范围

成员管理迁至管理员侧栏「配置 → 成员管理」。成员维护支持搜索、添加、授权、重置密码及启停；页头移除旧管理按钮。

新授权每应用一组操作，覆盖当前及后续新增渠道，支持未配置渠道的应用。准备和确认分别授予，覆盖该应用渠道对应的真实发布动作。菜单、应用范围、具体操作由服务端复核；旧指纹授权保留原范围，只有管理员显式编辑应用操作时才替换。

账号切换时同步可访问菜单与 URL，避免管理员页面残留导致成员审核详情无法打开。发布快照、回执、未知结果、版本保护和一次性授权规则保留。
