# 工作台整体配色第二轮复核

## 用户反馈与设计判断

用户对首轮配色仍不满意，要求按 ui-ux-pro-max 从整体设计重新复核。首轮已改善对比度，但画布、表头、选中导航和辅助文字的蓝灰倾向接近，缺少中性阅读层与品牌交互层的区分。

本轮采用纸白、石墨灰与少量航海蓝，具体职责见 [视觉系统](../design-system/MASTER.md)。现有结构、数据合同、发布流程及一次确认边界保持原有语义。

## 实现范围

- `palette.ts` 统一颜色来源，Ant Design Token 与根 CSS 变量由同一色板生成；懒加载页面及弹窗继承相同变量。
- 页面画布、白色卡片、中性表头、标签、控件边界及文字采用不同职责的中性色。
- 品牌标记、选中导航、页签、链接、选项和焦点使用统一蓝色；主按钮使用石墨色。
- 说明面板降低底色饱和度；成功、警告、错误分别定义深色文字和浅色背景，历史样式同步使用语义变量。
- 保留中文优先的 14px 桌面正文、目标复制、完整长包名、手机卡片和编辑焦点恢复。
