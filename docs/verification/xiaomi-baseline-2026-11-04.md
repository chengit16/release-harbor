# 小米接入前能力核对

**日期：**2026-11-04。

**范围：**只读官方资料和锁定 SDK `@huoye/app-ship@0.3.0`，未使用真实账号、查询或提交应用。此记录用于准备切片，不是小米发布验收。

## 官方资料

来源：[小米应用自动发布接口操作指南](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=1134)，页面标注更新时间为 2026-09-07。

官方说明该套接口用于查询、提交新应用、更新版本和修改资料；查询按开发者邮箱及包名定位，并返回当前是否允许新增／更新。认证使用平台 API 访问密码与 RSA 公钥，不能当成开发者登录密码。推送接口有独立的 APK、图标和资料要求，测试材料要求需随最新文档核对。

## 锁定 SDK 的代码事实

本地核对 `packages/provider-app-ship/node_modules/@huoye/app-ship/dist/index.js` 与 `index.d.ts`；公开发布件见[固定版本实现](https://unpkg.com/@huoye/app-ship@0.3.0/dist/index.js)。

| 项目 | 本次实际观察                                                                             | 对本项目的影响                                                              |
| ---- | ---------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| 凭据 | Xiaomi auth 包含 userName、privateKey 与 publicKeyContent／publicKeyPath                 | privateKey 表示 API 访问密码；不得复用 Apple 私钥输入模型，秘密留在可信进程 |
| 目标 | 查询使用 packageName 与 userName                                                         | 不能直接套用现有数字 appId 的全部规则                                       |
| 查询 | SDK 的 /dev/query 核对结果及新增／更新许可；无明确许可则停止                             | 首轮只做既有应用更新，预检及执行前都需确认真实允许状态                      |
| 动作 | RELEASE_PLATFORM_CAPABILITIES.xiaomi 默认 submit_review；上传成功投影为 review_submitted | 必须以提交审核向用户确认，不能标为华为式草稿                                |
| 重试 | SDK 将该动作声明为禁用自动重试                                                           | 产品仍须在自己的许可、执行和恢复边界落实，不能仅相信能力声明                |
| 资料 | 类型中存在新增／更新、图标／截图及测试资料入口                                           | 尚未逐项验证兼容性，不能仅透传 SDK 配置就开放写操作                         |

## 规划时待解决（历史核对）

1. 小米查询在本产品只读白名单中的签名、网络边界与响应守卫。
2. 账号材料与 RSA 公钥的格式、安全存储和页面提示；版本替换使旧预检失效。
3. 当前产品仅华为／Apple 的合同、账号、绑定、计划动作和安全回执如何渐进扩展；不顺带开放其他渠道。
4. 官方资料与 SDK 中更新提交所需图标及测试材料的兼容性；需要受控资料交接和冻结，不能公开保存测试账号秘密。
5. 小米更新提交、未知结果人工核对及真实后台证据的含义，不以“审核已提交”表示“审核通过”或“已上线”。

上述未解决项属于开发任务，当前不能声称小米链路可用。

## 本轮工程跟进

上述工程项已由本轮小米切片落实：包名目标、页面材料及测试表单、固定只读查询与更新许可、PNG／名称／隐私政策快照、单次提交及审核语义回执。实际实现对 SDK 缺口集中使用 provider 补充，不直接调用自动新增／更新上传器。工程及隔离浏览器证据见[验收记录](../../openspec/changes/add-xiaomi-updates/verification.md)，真实小米验收仍待用户对具体计划执行并核对后台，不能将本地测试改称真实受理。
