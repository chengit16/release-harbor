# 商店状态独立查询验证记录

日期：2026-11-06。根据用户更正，“审核状态”的默认查询目标来自应用商店绑定，不要求本机曾发布。旧执行的版本关联保留为独立历史能力。

## 本轮工程范围

- 新增独立绑定目录和显式只读查询端口；GET 仅返回绑定与缓存，POST 从可信绑定恢复商店目标，在独立 worker 内鉴权及读取固定官方接口。
- 新缓存使用独立 `store-status.json`，配置指纹隔离结果、持久预约防重复、失败保留上次成功及原时间。查询不修改计划、回执、授权、人工核对或旧锚点。
- 默认“商店状态”支持筛选、详情深链、刷新与前后退；“本地发布关联”保留旧执行入口。手机卡片与桌面表格分别展示，渠道限制在详情明确说明。
- 九个渠道绑定均可展示。魅族、荣耀、Apple 支持已核实状态；vivo 仅确认待审核；OPPO、应用宝、鸿蒙读取版本资料但未知审核阶段。小米缺公开审核查询接口，华为 Android 独立接口尚待核实接入，两者明确展示限制。

查询仅输出有限字段和固定错误分类，原始正文、审核附件、私人审核意见及秘密不进入公开响应。所有合成网络测试均不连接真实商店，不以本地测试推断用户账号权限或真实审核结果。

## 验证实绩

- 新增 12 项定向测试：无计划也能查询、归属及来源校验、拒绝目标覆盖、重复预约与重启、失败保留成功、改绑隔离、九渠道目录与未支持零调用，以及各官方只读路径、身份错配拒绝、未知状态投影和真实隔离 worker 启动。荣耀空在架资料不能制造上架证据，也有专门断言。
- 完整 Chrome 浏览器冒烟已通过：使用隔离临时目录和合成网络，覆盖无发布计划的魅族绑定、显式查询一次、刷新零查询、详情深链与前后退、原发布存储不变，以及旧执行关联入口兼容。第一次运行在既有账号选择场景超时，完整重跑通过；未改动业务实现以绕过断言。
- 1440px、375px、844px 的新列表及详情均检查溢出与对齐；桌面及手机截图已人工复核。
- `pnpm typecheck`（随构建运行）、`pnpm test`（211 项）、`pnpm build`、`pnpm format:check` 及 `pnpm test:smoke` 已通过。真实 worker 测试使用临时空凭据目录，只验证固定失败与关闭行为，不读取用户账号。

真实账号查询仍由用户在确定绑定上点击后核对；本轮没有读取真实秘密或发起真实上传、送审及上线。
