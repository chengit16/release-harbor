## 复验中发现的维护占用问题

完整浏览器场景在安装包清理处连续返回 409。隔离采样发现三个已离页的 GET（发布准备目录、安装包目录、批次目录）仍被计为活动请求，后台任务为 0；下载不是占用来源。根因确认：请求计数仅在正常 `onResponse` 释放，客户端关闭响应而处理稍后结束时，缺少释放路径。

补充真实回环 HTTP 回归：固定处理等待、确认服务端响应已关闭，再结束处理。修复前请求计数为 1 而失败；修复后通过。处理尚未结束继续拒绝维护；处理与序列化结束后，中断响应释放一次；正常流响应继续等待传输结束。未降低门禁阈值，不在客户端断开时提前取消后台事实。
