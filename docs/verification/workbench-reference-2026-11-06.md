# 参考页面的蓝白主题验收

## 设计依据与实现

按用户 2026-11-06 提供的四张后台页面截图，提取中性浅灰画布、白色内容卡片、统一蓝色主按钮与选中态、轻表头及黑灰文字层级。未复制截图中的人员、账号或业务数据。

- 画布为 `#f5f5f5`，内容面为白色，表头为 `#fafafa`，分隔线为 `#f0f0f0`。
- 主按钮、链接、页签、导航与焦点共用 `#1668dc`，选中底色为 `#e6f4ff`；蓝色适当加深以保持白字和浅蓝底上的可读性。
- 正文、说明及辅助信息分别使用 `#262626`、`#595959`、`#737373`。
- 成功、警告、错误的图标与文字分开取色，浅色状态底与深色文字组合，不直接照搬参考图中的偏浅小字。
- 商店目标的标题、说明、表格和配置边界说明纳入同一 Ant Design 白色卡片，保留手机卡片、完整目标和编辑焦点。
- 更新共享视觉规范和前端配色约定，后续页面沿用同一套蓝色主操作规则；没有新增依赖或修改发布动作。

## 实际验证

最终版本已通过 `pnpm typecheck`（随构建执行）、`pnpm test`（171 项通过、0 失败、0 跳过）、`pnpm build`、`pnpm format:check` 和 `pnpm test:smoke`。完整 Chrome 回归覆盖各渠道配置与发布、六渠道长目标、手机卡片、编辑焦点、问题中心和全页面窄屏。

额外 Chrome 使用独立回环服务和合成项目，检查表格、账号、发布页及账号向导；375px 竖屏与 812px 横屏无整页横向溢出，减少动态效果模式和 125% 缩放下主要入口可见，无未处理页面异常。商店目标与渠道能力表头颜色一致，输入焦点与主操作采用相同蓝色。

| 实测内容               | 对比度  |
| ---------------------- | ------- |
| 白底正文、目标及账号   | 15.13:1 |
| 白底配置版本与字段说明 | 7.00:1  |
| 白底链接               | 5.19:1  |
| 蓝底白字主按钮         | 5.19:1  |
| 浅蓝底选中导航         | 4.63:1  |

成功标签文字实测为 5.44:1，白底危险操作文字为 6.57:1。

这些是受检元素的实际结果，不代表全站无障碍审计。没有使用真实凭据或向商店提交；用户是否认可视觉效果仍以反馈为准。
