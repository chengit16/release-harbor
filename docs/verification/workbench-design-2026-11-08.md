# 工作台设计统一验收记录

## 本轮范围

按 [设计实施方案](../plans/workbench-design-plan.md) 完成公共视觉、发布与审核布局、配置与帮助精简。未增加商店路由、权限、自动提交或秘密持久化。

## 验证环境与边界

自动测试与 Chrome 使用隔离临时目录、合成应用和内存材料，不触及用户账号；截图保存在忽略目录 `artifacts/`。原发布确认、失败保稿、渠道差异、账号关联删除保护和恢复预览继续由完整冒烟覆盖。

## 实际结果

类型检查、270 项自动测试、构建、格式与完整 Chrome 冒烟通过。完整冒烟继续覆盖账号创建／维护／改名／替换／删除保护、安装包检查与失败保稿、单渠道和批次的一次确认、Apple 审核及手动发布、备份恢复、只读跟踪与通知。

新增设计回归实际检查：

- 1440×900 桌面首条发布记录位于 442px，审核记录位于 444px，均进入首屏；手机改为分页卡片，版本、状态和详情直接可读。
- 发布搜索可筛选本机结果，空结果明确呈现；刷新保留 URL 搜索值，清空后恢复记录。手机筛选展开、刷新、浏览器后退保持正确范围。
- 手机三个主要审核页签完整可见，辅助历史经“更多”进入；账号页仅保留一个同名页标题，维护抽屉可完成既有操作。
- 发布、审核、应用、账号、设置、帮助入口覆盖 1440px 桌面、375px 手机、844px 横屏和 720px 可用宽度；基础标题与内容起点容差不超过 2px，发布面包屑与应用标题继续对齐。
- 验证键盘“跳至页面内容”、单一页标题和低动效；导航、筛选、刷新及帮助展开产生的非 GET API 请求为零。
- 人工复核桌面首页、手机审核卡片、发布编辑区及横屏指南截图。错误、材料检查失败、未知结果与执行确认继续在原业务区明确呈现。

## 本轮回归中发现并修复的问题

- 844px 商店指南被表格自动最小宽度撑开：为网格及其子项设置 `min-width: 0`，整页宽度恢复到视口范围，表格只在自身容器滚动。
- 手机审核列表记录较多时页码被容器裁切：使用简洁分页，并核对前后翻页及记录恢复。
- 新账号维护抽屉的自动测试沿用英文关闭名称：通过 Ant Design 的公开 `closable` 属性提供中文可访问名称，测试按实际入口执行。
