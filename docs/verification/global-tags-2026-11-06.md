# 全局浅色语义标签验收

## 设计与实现

根据用户提供的两组标签参考，统一浅红、浅蓝、浅绿、浅黄背景与较深文字，沿用当前语义色板。默认标签为无可见描边的小矩形：12px 字号、500 字重、20px 行高、3px 圆角、左右各 8px 内边距，无阴影。

通过 `apps/web/src/app/tagTheme.ts` 和入口 ConfigProvider 的公开 Tag 配置覆盖现有页面，不逐页复制样式，也不新增全局 `.ant-*` 样式覆盖。

| 语义 | 兼容的现有颜色名称               | 用途                         |
| ---- | -------------------------------- | ---------------------------- |
| 中性 | 无颜色、default                  | 渠道、平台、计数及普通元信息 |
| 信息 | blue、cyan、geekblue、processing | 信息及处理中状态             |
| 成功 | green、lime、success             | 已有业务定义中的成功事实     |
| 警告 | gold、yellow、orange、warning    | 异常及待处理提醒             |
| 错误 | red、volcano、error              | 失败或必要信息缺失           |

颜色别名共用同一套文字和背景，避免页面同时使用 `green` 与 `success` 时出现色差。业务文案和状态判定保持原样；显式实心、描边、禁用及未知自定义颜色保留组件规则，业务长状态文字仍可换行。

## 浏览器验证

使用真实 Chrome 加载当前主题及标签配置，检查五种语义与颜色别名的实际计算样式；确认默认标签无描边、统一尺寸与圆角，显式描边／实心及禁用态继续生效，长文字可换行，375px 视口无整页横向溢出，无未处理页面异常。

五种标签文字与背景的实测对比度分别为：中性 6.42:1、信息 4.63:1、成功 5.44:1、警告 6.53:1、错误 6.01:1。

另在独立回环服务中创建合成项目、应用与六渠道绑定，检查商店目标、发布页、账号页和账号向导。账号页成功标签、桌面与手机布局、表头一致性、输入焦点、减少动态效果与 125% 缩放检查通过。合成数据不包含真实账号秘密，也未向商店提交。

预览与计算样式记录位于忽略目录：`artifacts/global-tags-preview.png`、`artifacts/global-tags-verification.json`、`artifacts/global-tags-page-accounts.png` 和 `artifacts/global-tags-page-verification.json`。

## 账号标签反馈后的视觉修正

用户反馈账号状态标签仍然偏厚。复查确认首版的 500 字重、左右 8px 留白和深色绿色文字增加了中文标签的视觉重量。本轮统一改为 400 常规字重、左右 6px 留白、2px 圆角，字号为 12px，行高为 20px。

标签文字从唯一色板中的 `harborTagText` 单独导出，成功使用 `#2f850b`、警告使用 `#a15c00`、错误使用 `#cf3030`。与浅色底的实测对比度依次为 4.56:1、4.99:1、4.66:1。蓝色和中性分别为 4.63:1 和 6.42:1。

Chrome 验证了实际账号页的“已配置 · 待应用预检”标签，计算样式为 12px、400 字重、20px 高、6px 左右留白及 2px 圆角。五种语义、颜色别名、显式变体、禁用态、长文换行、375px 窄屏和横屏检查通过，页面无未处理异常。预览位于忽略目录 `artifacts/global-tags-refined-preview.png` 和 `artifacts/global-tags-refined-account-tag.png`。

本轮通过 `pnpm typecheck`、`pnpm test`（175 项通过）、`pnpm build`、`pnpm test:smoke` 以及本次五个修改文件的 Prettier 检查。整库 `pnpm format:check` 当次报告 25 个其他在改文件尚未格式化，涉及多渠道批次及执行器等并行改动。
