# SDK 与本地环境静态核对

**日期：**2026-11-03  
**范围：**第一期 P1-0，读取锁定依赖的实际声明与实现，不调用真实账号或商店。

## 核对依据

本地 `packages/provider-app-ship/node_modules/@huoye/app-ship` 的 `package.json`、`dist/index.d.ts` 和 `dist/index.js`，版本为 `0.3.0`；版本来源及供应商接口后续仍需在相应切片重新核实。

| 项目         | 静态结论                                                                                          | 产品落地约束                                                           |
| ------------ | ------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| 产物检查     | 导出 `inspectReleaseArtifact`，当前适配层已投影安全身份字段。                                     | 后续检查真实字节，路径留在可信执行侧。                                 |
| 发布计划     | 导出 `createReleasePlan`，输入包含路径、摘要、版本、Profile 与目标配置等。                        | SDK 输入不能直接成为公开浏览器合同，需独立安全映射。                   |
| 确认执行     | 导出 `assertReleaseConfirmation`、`executeReleasePlan(s)`，确认包含计划、平台、动作、摘要与时间。 | SDK 确认不能代替产品的可信身份、授权范围、有效期及消费校验。           |
| 首批动作     | `huawei` 默认 `create_draft`，`app_store` 默认 `upload_build`。                                   | 只保留产品定义的首批目标；不扩大为自动送审或上线。                     |
| 凭据提供器   | 声明提供 Profile 元数据与本机解析；默认实现检查 `darwin`，使用 macOS Keychain。                   | 本轮只保存引用，不访问个人 Keychain；引用存在不代表有效。              |
| Profile 字符 | SDK 允许字母或数字开头、最多 80 字符。                                                            | 当前产品采用字母开头、最多 64 字符的保守子集，后续扩大需兼容现有数据。 |
| 回执         | 执行结果包含 report 与 receipt，并有独立本地 ReceiptStore。                                       | 需审查脱敏、归属和任务关联；SDK 项目目录不能成为产品唯一归属。         |

## 环境检查

- Node.js：`v24.19.0`，符合项目 Node 24 要求。
- 可找到 `/usr/bin/xcrun` 与 `/usr/bin/security`；`xcrun --find altool` 返回已安装 Xcode 中的工具路径。
- 工具存在不代表已登录、凭据可访问、网络可达或真实上传可用；以上均未验证。
- 当前未安装 OpenSpec CLI；已建立仓库内规格文档约定，没有宣称通过 CLI 校验。
