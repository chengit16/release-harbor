# 百度移动应用平台接入可行性核对

核对日期：2026-11-06。范围是 Android APK 向百度手机助手／百度移动应用平台分发，不包含百度智能小程序、移动统计、推送、地图、智能云文件上传或广告转化 API。本轮只读公开页面和公开前端资源，没有登录真实账号、申请密钥、上传文件或提交审核。

## 结论

**当前未达到“确认可接入”的门槛，暂不加入开发计划，也不新增渠道入口。**

这不等于“百度没有接口”或“技术上不能实现”。官方 2026 年帮助文档明确提及 API 上传，说明存在正式能力线索；但本轮没有取得足够的官方协议及准入证据，无法确认它可供当前开发者申请、是否覆盖手机助手自然分发，以及如何完成可核对的更新送审。不能把商业推广渠道包的上传成功当作手机助手分发成功。[官方 APP 登记指引](https://app.baidu.com/newapp/docs/政策中心/APP核准（原备案）指引/)

## 目前缺少的接入依据

| 现有发布流程需要的能力   | 本轮结果                                                                   | 对接入决策的影响                                                        |
| ------------------------ | -------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| 服务端认证及密钥申请     | 未取得适用于应用分发的正式凭据申请、认证、权限及有效期文档。               | 不能编造 User ID、Token 或把百度其他产品的密钥当作发布凭据。            |
| 只读查询已有应用         | 未取得包名、应用 ID、来源版本与可更新状态的正式查询合同。                  | 不能安全地完成当前自动准备中的目标及来源核对。                          |
| APK 上传                 | 官方确认存在 API 上传能力线索，具体端点、文件协议和授权范围未核实。        | 不能仅据此承诺本地 APK 自动发布，也不能复用网页内部调用当稳定开放接口。 |
| 更新及提交审核           | 未确认自然分发的上传与送审是一个动作还是两个动作，也没有确定受理回执结构。 | 无法如实实现“摘要确认一次 → 提交审核 → 结果核对”。                      |
| 受理／审核状态           | 未取得应用分发的查询接口、状态字典及任务／版本关联规则。                   | 未知结果恢复缺少可靠依据，不能把 HTTP 成功或文件上传当审核受理。        |
| 审核后立即／指定时间上架 | 本轮没有取得对应的官方参数、时区或受理规则。                               | 不展示为支持，也不以自动更新替代指定时间上架。                          |
| 当前账号是否能新申请 API | 公共帮助的接口线索不足以确认自助开放、白名单或合作申请条件。               | 不因已有普通开发者认证就假定具备 API 权限。                             |

这里的“未取得／未确认”是证据边界，不是宣告这些能力不存在。公开前端资源可见应用列表、认领、商业推广及账号页面，但没有在本轮检索到足以替代正式开放协议的说明；未调用其中的账号或业务接口。

锁定的 `@huoye/app-ship@0.3.0` 能力注册、预检平台列表、声明及构建产物中未发现百度适配。这意味着即使取得正式接口也需要独立 Adapter，不能直接启用 SDK 开关；它本身不构成“百度无法接入”的证据。依赖版本见 [provider 包声明](../../packages/provider-app-ship/package.json)。

## 商业推广功能不能代替应用分发

官方商业推广提交文档支持本地 APK 或链接渠道包，要求填写应用资料；这是该文档所在业务的提交规则，不能自动扩大为所有手机助手分发 API 的规则。[商业推广应用提交](https://app.baidu.com/newapp/docs/流量服务/商业推广/应用提交)，页面更新于 2026-01-12。

官方“自动更新”是针对已审核通过且名称不变的链接渠道包：固定下载链接、MD5 改变后按天更新。它不是 Release Harbor 确认后立即上传／送审的回执，也不是用户指定的审核后上架时间。[自动更新](https://app.baidu.com/newapp/docs/流量服务/商业推广/自动更新)，页面更新于 2022-08-11。

“批量功能”主要描述 Excel 批量新建及对链接渠道包的手动更新、编辑，同样不足以提供服务端认证和自然分发送审合同。[批量功能](https://app.baidu.com/newapp/docs/流量服务/商业推广/批量功能)，页面更新于 2022-08-11。

## 决策边界

按用户“能做再加，否则不规划”的要求，本轮到可行性核对结束：不新增百度菜单、渠道枚举、假凭据字段、OpenSpec 实施变更或排期待办。

只有后续能取得官方应用分发 API 文档，以及当前账号可申请或使用该权限的非秘密证据，才足以重新判断。需要证据覆盖认证与准入、应用目标查询、APK 更新送审、明确回执及恢复语义；若上架时间能力缺失，应明确实际范围，不能默认为已有支持。这是重新判断的准入条件，不是已经安排的开发计划。

官方提供应用问题反馈入口，可供用户自行向平台确认文档及准入范围；本轮未代发邮件、申请权限或联系工作人员。[官方问题反馈入口](https://app.baidu.com/newapp/docs/新手指南/问题反馈入口)，页面更新于 2024-09-09。
