# 商店查询与变化记录验收

日期：2026-11-07。第三期查询证据留存切片，使用合成快照、临时目录和隔离 Chrome，不使用真实账号或执行上传、送审、上线。

## 范围与数据规则

- 独立商店缓存写 schema3，兼容 schema1／2；GET 不写迁移，不从旧最近缓存伪造此前查询历史。默认和指定构建的最近缓存继续保留。
- 每个绑定指纹最近三十次完成查询，包含成功、失败及未变化；与最近结果同队列原子写入。人工记录不进入官方历史，改绑隔离旧目标。
- 公开可选 queryHistory 仅由既有安全快照组成，严格校验目标、渠道、每绑定上限及字段；未知字段、私密意见、伪造来源或损坏文件拒绝。
- 只比较同一查询范围下最近的较早成功；只有唯一且一致的版本 ID／版本名／构建号允许比较，缺 ID 与构建号时不猜。不同绑定、渠道、构建范围和定位变化不混用。
- 失败不产生状态变化；未返回不等于下架，查询时间不是变化实际发生时间。结果不能回填执行锚点、改变回执或解除未知保护。小米及应用宝精度限制保持。
- 页面折叠、每页五次，长字段与标签换行；展开、分页、刷新均零商店查询。上限是滚动留存，不是永久审计档案。
