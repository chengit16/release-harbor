# 隧道入口五分钟接收中断核对

对应问题 RH-0072，核对日期为 2026-11-11。

## 现象与原因

用户通过指定 cpolar 域名在发布页上传约 154 MiB APK，页面显示“服务响应无法解析，请刷新后重试”。新记录从 09:41:09 至 09:46:11，耗时 301.437 秒，失败分类为 `upload_incomplete`。此前 120 秒的 `upload_timeout` 与本次分别保留原事实。

实际隧道上游为本机 5178 Vite 开发服务，再代理至 4399 API。隧道提供的前端合同已包含一小时总期限，排除了仍加载旧 125 秒客户端期限这一原因。对应连接日志显示，约五分钟期间向 5178 传递了 39,583,744 字节，5178 最后向隧道返回 51 字节。

使用仓库真实 Vite 配置启动隔离服务器，读取到原生 `requestTimeout` 为 300000 毫秒。将原生接收期限按千分之一缩放后，持续每 50 毫秒发送正文仍返回空正文 HTTP 408；修复前回归明确失败。客户端面对空正文 408 或 HTML 504 都只显示 JSON 解析错误，另有回归复现。

Node HTTP 的默认请求正文接收期限为五分钟，到期返回 408 并关闭连接。Vite 这一层原生期限没有随安装包合同同步。超时扫描有周期，真实慢速验证需覆盖五分钟和扫描余量。[Node 官方 HTTP 文档](https://nodejs.org/docs/latest-v24.x/api/http.html#serverrequesttimeout)

## 处理

Vite 开发入口从共享公开合同取得上传总时限，HTTP 服务器允许一小时加五秒接收窗口。API 继续独立核对实际字节、两分钟无进度、一小时总期限、长度、摘要、配额与归属。请求头期限保持既有值。

客户端遇到非 JSON 失败响应时保留 HTTP 状态。408／504 显示超时，其他失败显示连接异常，并引导刷新记录核对实际结果，避免解析错误掩盖失败来源。

已有慢速浏览器专项加入真实 Vite 代理，九段合成 IPA 每隔 45 秒发送，总耗时约六分钟。在 336 秒时核对浏览器仍等待和服务端仍接收，完成后核对 202、SHA-256、独立身份检查和刷新恢复。测试使用独立端口与临时目录。

## 验证结果

`pnpm typecheck`、`pnpm test`（301 项）、`pnpm build`、`pnpm format:check` 和完整 `pnpm test:smoke` 通过。完整 Chrome 使用独立 4468／4469 端口，覆盖发布页内上传、正常与失败反馈、批次默认说明、日期回填及多视口。

修复前执行 `node --import tsx --test tests/vite-upload-timeout.test.ts`，实际 Vite 配置代理返回空正文 408，持续传输应完整到达上游的断言失败；修复后同一命令通过，并核对了完整字节长度和 SHA-256。`tests/api-client.test.ts` 中空正文 408 与 HTML 504 的回归也从失败变为通过，JSON 业务错误和成功响应格式校验继续通过。

`node --import tsx scripts/artifact-upload-timeout-smoke.mjs` 通过。336 秒时浏览器仍等待、服务端仍接收；362.694 秒完成真实 Vite 转发后的 HTTP 202、独立合成 IPA 身份检查、SHA-256 核对及刷新恢复，浏览器无未处理异常。

另用真实 Chrome 拦截合成上传响应为空正文 408，页面显示“请求超时（HTTP 408），请刷新记录核对处理结果”，截图已人工核对。

实际隧道探针以完整请求头、每十秒发送少量 JSON 正文的方式对比 4399、5178 和指定域名，最终正文为空对象，由项目字段校验拒绝，不创建项目或安装包、不调用商店。该探针只证明相同网络入口的长请求接收结果，合成安装包完整流程由隔离浏览器专项验证。

修复前 5178 在 309.178 秒返回空正文 408；同轮 4399 与域名请求在约 310 秒完成正文并返回预期 JSON 400。原生超时按周期扫描，临界请求的结果受抵达时刻影响，因此修复后延长探针至六分钟。

修复后实际运行中的三个入口均完整接收六分钟正文并返回相同安全 JSON 400，分别耗时 360.101、360.103 和 360.238 秒。该 400 是空对象缺少项目名称的预期拒绝，证明正文到达了 API 字段校验。实际域名通过这一检查，未据此宣称用户原 154 MiB APK 已复验成功。

修改 Vite 配置后，现有开发服务已自动重启加载；真实域名探针已核对生效。页面刷新获取新的错误提示。前次 135 秒直连 API 验证没有覆盖 Vite 五分钟门槛，本次将该入口与扫描余量加入验证。
