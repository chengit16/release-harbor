# 失败与已清理安装包记录删除

本文记录首次交付范围。后续修正了普通并发请求和其他安装包活动导致的误拦截，当前删除准入见[并发删除修复记录](artifact-delete-concurrency-2026-11-11.md)。

## 范围与边界

用户要求删除安装包页残留的失败和已清理记录。本次提供详情卡片、应用内存储列表及本机设置的单条／批量删除，使用 Ant Design 确认框说明记录、残余文件及不可撤销影响。

删除复用可信来源、操作标记、显式确认及维护独占门禁；整组选项须属于当前本机目录且均为失败终态，最多一百项。可用项必须先清理，接收／检查及活动准备／执行期间拒绝删除。服务端不接受客户端状态、归属或文件路径。

删除独立安装包记录与残余文件，保留预检、发布计划快照、历史回执、授权消费和安全保护。被历史引用也可删除；旧计划依赖仍失效，重复版本和未知结果不会因删除解除。存储格式及公开产物合同不变，旧备份仍按原恢复协议处理。文件删除不是跨文件事务，异常后重新读取实际事实，不自动重试。

## 验证

专项隔离测试已通过：失败及已清理记录批量删除、目录移除、初始化后不恢复、旧快照和回执不变、版本防重仍阻塞、删除后备份预览可用；混合可用项、未知 ID、跨空间、活动接收／检查和维护占用拒绝且无部分删除；API 来源、标记、显式确认、字段白名单、重复与过量 ID 拒绝。

- `pnpm typecheck`、`pnpm test`（301 项）、`pnpm build`、`pnpm format:check` 通过。
- `pnpm test:smoke` 通过：失败卡片单条删除、存储已清理项删除、取消不删除、接口拒绝后关闭并刷新、筛选失败项并批量删除、混选可用项禁止批量删除、两个列表同步与刷新后保持删除结果。可用安装包仍保留。
- 人工核对 1440／375／844 视口删除确认框与手机失败卡片，确认操作可见、文案可读、窄屏无横向溢出。

所有数据均为临时目录和合成材料，不涉及真实商店请求或用户安装包删除。
