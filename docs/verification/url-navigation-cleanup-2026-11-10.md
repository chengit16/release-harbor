# 导航 URL 与渠道摘要精简核对

日期：2026-11-10。对应 RH-0066 与 RH-0064。

用户随后明确要求发布页也只保留菜单地址；本文记录第一轮清理验证，原“必要字段继续保留在 URL”的做法已由[菜单短地址更正核对](menu-only-navigation-2026-11-10.md)取代。

## 问题与处理

共享 URL 更新原来只合并参数，页面分别局部清理，造成问题档案、本机设置、帮助页签及发布筛选跨菜单累积。已用真实 `updateUrlState` 入口复现：切换商店账号后仍残留发布工作区、已选渠道和其他页签参数。

现统一按页面与子视图保留字段，省略默认状态与重复发布模式。菜单进入独立入口，跨页业务链接显式携带目标；兼容旧配置、计划、批次及 Apple 审核深链，通过 replaceState 原位清理，不新增历史。

发布详情只保留应用、操作、渠道选择及当前记录定位。已选绑定 ID 用于恢复精确选择，继续保留；不能以缩短 URL 为由省略选择身份。发布列表筛选随当前历史项保存，不进入浏览器持久缓存；当前标签页刷新仍可返回原筛选，跨浏览器或新标签页直接打开详情时返回默认列表。URL 与历史状态均不构成执行许可。

本次渠道摘要仅显示加粗品牌，华为显示“华为”、iOS 显示“Apple”，去掉该处的 App ID 和包名；最终发布确认仍保留完整目标。
