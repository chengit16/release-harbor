# 项目问题档案

此目录持续收集当前可用会话、代码和验收文档中可核实的问题，以及解决方法和验证边界。

- [结构化档案](catalog.json)：问题事实的唯一维护入口；稳定编号不随分类或标题变化。
- [菜单与收集方案](../plans/problem-knowledge-center-plan.md)：分类、状态、AI 记录流程和后续页面设计。

“问题与解决”菜单、公开合同与只读查询已实现，支持分类、搜索、分页和关联详情。构建时验证并复制目录及证据，页面展示当前发布版本档案。后续 AI 在问题发现及处理完成时更新，不能把猜测写成已确认根因，也不能把代码修复等同于历史发布成功。仅记录经过筛选的安全描述，不保存真实凭据、安装包或未脱敏附件。
