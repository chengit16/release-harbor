# Release Harbor 视觉系统

## 设计方向

纸白、石墨灰与航海蓝。工作台承载账号、安装包和发布事实的长时间阅读，视觉重心放在内容与当前操作位置。白色内容面保持明亮，中性灰划分层级，少量蓝色建立品牌与交互关联。

本系统用于现有 React + Ant Design Web 工作台。沿用现有导航、表单、合同及发布确认流程，不引入新的组件库或外部字体。

## 上一轮复核

用户在第一轮可读性调整后反馈仍不满意。上一轮的正文对比度已有改善，但画布、表头、导航选中底、标签和辅助文字普遍带蓝灰，导致中性色与强调色的职责接近；品牌标记又缺少色彩识别，整页显得偏冷、偏灰。

本轮把中性色与强调色分开：中性层支持阅读，蓝色指示位置与交互，绿色／黄色／红色表达已有的状态事实。工程检查只能确认实现与可读性，视觉是否符合用户偏好仍以实际反馈为准。

## 使用规则

- 蓝色集中于品牌、位置与可操作内容。表头、普通卡片、默认标签及大段说明使用中性色。
- 主按钮保持石墨色。编辑、查看、复制等链接使用航海蓝；每个业务区域的主操作有清晰的视觉优先级。
- 普通说明面板使用接近白色的底色，图标表达信息类型。成功、警告、错误使用低饱和底色和对应深色文字，并保留文字与图标。
- 当前导航使用淡蓝底与蓝色文字；当前页签使用蓝色文字及下划线。悬停、选中、禁用分别定义，禁用不依赖鼠标悬停解释。
- 白色卡片使用细中性边框；分隔线不与正文竞争。表格保留白色行与浅中性表头，长身份字段完整换行并可复制。
- 保留中文优先的 14px 桌面正文，标题与正文使用同一无衬线体系；次级信息依靠大小、间距和字重建立层级。
- 窄屏沿用自适应表格／卡片，保留可见焦点、键盘返回和完整操作入口；遵循减少动态效果设置。

## 实现来源

唯一色板为 `apps/web/src/app/palette.ts`。Ant Design Theme 直接引用该色板；`main.tsx` 在首屏渲染前将对应 CSS 变量挂载到文档根节点，使普通页面、懒加载页面与弹窗 Portal 共享颜色。

页面复用语义变量，不另写一套十六进制颜色。新增组件应先确定颜色职责，再选择主题 Token；发布状态的业务判断不进入主题。

## 设计依据

本次按本机 ui-ux-pro-max 技能的颜色语义、视觉层级、状态可辨及对比原则复核。本机 `scripts` 和 `data` 为指向缺失目录的普通文本文件，内置 `--design-system` 命令无法运行，未宣称得到其自动推荐结果。

组件实现遵循 [Ant Design 主题接口](https://ant.design/docs/react/customize-theme/)，颜色分工参考 [Radix Colors 的背景、交互与文字色阶说明](https://www.radix-ui.com/colors/docs/palette-composition/understanding-the-scale)。本项目采用上述明确色值，未安装 Radix 依赖。
