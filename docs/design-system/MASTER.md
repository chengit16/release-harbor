# Release Harbor 视觉系统

## 设计方向

以用户 2026-11-06 提供的四张后台页面为视觉参考，采用浅灰画布、白色内容卡片、统一蓝色主操作和黑灰文字。列表、配置、表单与工作台共享颜色职责，让当前操作和真实状态清楚可辨。

本系统用于现有 React + Ant Design Web 工作台。保留现有导航及业务流程，不新增组件库、外部字体或依赖，不复制参考截图中的人员、账号或业务数据。

## 参考页面提取

- 侧栏、顶栏和内容卡片使用白色；页面留白区使用中性浅灰。
- 主按钮、链接、当前页签和选中导航共用蓝色，选中背景为浅蓝。
- 表头与次级分组使用很浅的中性灰，细分隔线降低视觉干扰。
- 标题和关键值使用深灰，说明使用中灰；必要的小字与占位信息保持可读。
- 成功、警告和失败分别使用绿、黄、红色提示，并配合文字或图标。

| -------------- | -------------------- | ------------------------------------ |
| 内容面         | `#ffffff`            | 侧栏、顶栏、卡片、表单、表格行、弹窗 |
| 画布           | `#f5f5f5`            | 工作区背景与普通分组底色             |
| 表头           | `#fafafa`            | 表格头部与轻量分组                   |
| 分隔线         | `#f0f0f0`            | 卡片边界和内容分隔                   |
| 控件边界       | `#d9d9d9`            | 输入、选择与次按钮的正常边界         |
| 主文字         | `#262626`            | 标题、正文、目标值和账号名称         |
| 次级文字       | `#595959`            | 说明、字段类型、版本与时间           |
| 辅助文字       | `#737373`            | 占位与较弱提示                       |
| 主蓝色         | `#1668dc`            | 主按钮、品牌、链接、导航、页签和焦点 |
| 蓝色悬停       | `#1259bd`            | 主操作及链接悬停                     |
| 蓝色按下       | `#0e499b`            | 主操作及链接按下                     |

主蓝色保留参考图的明快蓝色方向，并适当加深，以保证白色按钮文字与浅蓝选中态上的文字可读。状态图标可比标签文字更鲜明，文字使用单独的深色色阶；不会直接照搬截图中偏浅的小字和状态文字。

## 使用规则

- 同一蓝色同时承担主操作与交互强调。保存、准备和确认按钮采用蓝底白字；查看、编辑、复制使用蓝色链接；次按钮使用白底灰边。
- 页面以白色卡片组织内容。商店目标的标题、说明、表格和配置边界说明放在同一白色区域，卡片内的表格保持轻量分隔。
- 默认标签、筛选轨道、普通分组使用中性灰；只有选中状态使用浅蓝，状态提示保留独立语义。
- 提示面板使用浅色背景与深色文字，保留图标和真实业务文案；不以颜色单独表达发布成功。
- 中文优先的 14px 桌面正文与无衬线标题保持一致，次级信息依靠字重、间距和文字色阶区分。
- 手机保留卡片、完整长目标和编辑返回焦点，支持键盘操作和减少动态效果设置。

## 实现来源

全局标签采用参考截图的轻量样式：20px 行高、12px 字号、500 字重、3px 圆角、左右各 8px 内边距，使用浅色背景和彩色文字，不添加阴影或可见描边。蓝色表示信息／处理中，绿色表示成功事实，橙色表示警告，红色表示失败，普通元信息使用灰色。已有状态文案与含义保持原样。

`app/tagTheme.ts` 通过 ConfigProvider 的公开 Tag 配置统一现有页面，将 `blue`／`processing`、`green`／`success` 等别名映射为同一色阶。长状态文字按业务样式换行；显式实心、描边、禁用和未知自定义颜色保留组件规则，不全局强制单行。

唯一色板为 `apps/web/src/app/palette.ts`。Ant Design Theme 直接引用该色板；入口将 CSS 变量挂载到文档根节点，使页面与弹窗使用相同颜色。

按 ui-ux-pro-max 的颜色语义、视觉层级、状态可辨和对比原则复核。本机技能的 `scripts` 与 `data` 为指向缺失目录的文本文件，不能执行内置 `--design-system` 检索，不宣称获得自动推荐结果。本次配色以用户提供的页面参考为主。
